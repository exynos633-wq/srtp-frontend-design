## 文件同步与工程状态

当前资料统一在根目录：`UI设计/` 保存深色视觉、参考图和动效，`工程设计/` 保存工程与接口草案，`项目搭建计划.md` 记录产品范围。共同采用 **深色 v1.0 + 复杂动画方案**，通过本入口协作。

前端选型继续采用 React + TypeScript + Vite、Three.js + React Three Fiber、CSS Modules、React Router、TanStack Query、MSW；复杂时间轴增加 GSAP + @gsap/react，连续转场采用 Flip。确切版本仍需在初始化时锁定并验证。

接口文件仍是待前后端确认的草案；渲染方式仍待真实模型测试。AI 助手属于首期，目前按负责人提供完整组件规划，我们负责挂载、深色主题及页面适配；具体组件形式和配置待交付对接，尚未视为已完成。

首期 10 个模型，现有三个作为开发样例；内容和封面由 AI 基于模型辅助整理，演示可用明确占位。仅国内城市，目录及城市卡片按最新发布优先、一次展示全部；介绍为支持换行的纯文字，不加作者／日期字段。AI 组件仅挂公开端，未交付先隐藏入口。适配电脑与手机主流浏览器，微信内置浏览器不纳入本期验收，流畅度优先。

当前尚无前端工程，本轮完成的是设计资料整理与依据同步。

## 仓库与本地模型

本仓库保存工程设计、分阶段编码提示词、UI 参考图、制作记录和会议纪要。三个原始模型 `ancient_chinese_courtyard_park.glb`、`great_wall_survey.glb`、`丘陵.ply` 保留在本地，不纳入 Git；克隆仓库不会自动获得模型文件。页面与动画可以先按文档使用明确占位，进行真实渲染验证前须向模型负责人取得对应版本的文件。原始文件不得因初始化工程就复制进前端公开目录或构建包。
