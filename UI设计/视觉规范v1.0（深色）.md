# 建筑模型展厅 · 最终视觉规范

版本：1.0 · 2026-10-17  
视觉方向：空间图谱 / Spatial Atlas。该名称仅指风格，正式产品名称另行提供。  
文档状态：视觉设计收敛完成；实现、资产生产与设备验收尚未启动或完成，不在此冒充验收通过。

本文件是后续实现的单一视觉依据，已吸收前序规范的共用规则。交付物仅此 Markdown 文档，不含代码、交互原型或新制作的设计资产。带有“待实现验证”的数值是供实现起步的设计建议，验证后只校准对应参数，不重新开启风格选择。

## 1. 设计原则与范围

**以极简暗色承托连续的三维场景，用局部玻璃和少量 HUD 细节说明位置与操作状态。**

关键词：沉浸、悬浮、空间秩序。

1. 真实地球和建筑材质承担主要视觉表现；保留院落的浅石材与暖木构、长城的绿植和灰石，不统一染青。
2. 冷青用于主要操作与地球点位；模型图像附近的选中角标用冷银。禁止冷青环绕模型轮廓、整圈高亮或彩色外发光。
3. 玻璃表示场景前后关系；长文、表单和工作界面使用实色。
4. 动效采用空间镜头、分层时间轴与连续转场，详见 [动效设计 v1.0](动效设计v1.0.md)。地球入场、点位联动与观看转场均纳入首期；持续自动旋转与装饰效果按该文件执行。
5. 电脑与手机共享色彩、组件语义和信息内容；通过重排与材质适配保持可读性。

信息架构与业务流程固定：

- 公开端：三维地球探索、全部作品、同一个作品详情。
- 点位气泡：每个点代表一座城市，气泡显示城市名及该城市已发布模型的封面、名称和详情入口；手机仍在点位附近出现。城市选填，未填模型只在全部作品与详情中浏览。
- 详情：先封面，点击“开始预览”才申请远程渲染；已有旋转、缩放、复位、放大查看和结束操作。资源繁忙与断线均手动重试。
- 介绍：建筑介绍、选填建模说明；作品点赞和评论仅保留区域与接口意图，不放假数量、假评论。
- 后台：管理员登录、作品管理、上传／编辑、预览、手动发布／下架；不完整资料可存草稿，已发布介绍与封面保存后直接更新公开内容。
- 模型文件替换仍先下架、等待已有预览结束、替换并自行检查后手动发布。发布不新增强制预览记录校验。

键盘、触摸与鼠标规则是上述能力的输入等价方式，不增加新的业务模块。搜索、统计、打卡、消息、路线、下载和实际评论／点赞功能均不由本规范引入。

### 2.2 玻璃的统一规则

**只有叠在场景／远程画面上的短内容层使用玻璃；手机导航与所有工作／阅读界面使用实色。** 这是按使用位置和可读性执行的一套规则。

| 位置 | 默认材质 | 不透明度与模糊 |
| --- | --- | --- |
| 宽度 ≥768 px 的首页导航，且场景延伸到其背后 | `#080D12EB` | 235/255，约 92%；模糊 12 px |
| 宽度 <768 px 的顶部导航；全部非首页导航 | 实色 `#080D12` | 无模糊 |
| 地球上的单个建筑气泡外壳 | `#121D26E0` | 224/255，约 88%；桌面 12 px、手机 8 px 模糊 |
| 查看器现有控制条，叠在画面内时 | `#121D26EB` | 235/255，约 92%；桌面 12 px、手机 8 px 模糊 |
| 控制条移出画面后 | 实色 `#121D26` | 无模糊 |
| 封面图像底、目录、详情介绍、评论预留、登录、后台 | 对应实色底 | 无玻璃 |

首页同时最多导航和一个气泡，不叠加常驻侧栏。**玻璃面积上限为当前首页可见视口的 22%**：以可见玻璃面板外接矩形的并集面积计算，包含其内部图像区域，不重复计算交叠；分母使用浏览器当前可见页面区域，不包含浏览器工具栏、键盘或长页面未显示部分。

统一降级顺序：

1. 气泡加入后超过 22%，气泡外壳直接改实色 `#121D26`，尺寸、内容与邻近点位的位置关系保留。
2. 仅导航仍超过预算，则导航也改实色 `#080D12`。
3. 不支持背景模糊、用户偏好降低透明效果或实际合成对比不足时，同样使用对应实色。不得通过降低文字透明度或缩小按钮挽救玻璃。

例如 390×844、280×224 的手机气泡约占视口 19%，可保留玻璃；320×568 时同尺寸约占 34.5%，按规则改实色。这些是布局计算，未声称已完成设备实测。玻璃边缘只留弱顶边反光，不绘制整圈冷青高亮。

### 2.3 对比度判定方法

采用 sRGB 相对亮度计算，比例为较亮色亮度加 0.05 除以较暗色亮度加 0.05。表格显示值四舍五入至两位，判定采用未四舍五入的数值。本轮做的是颜色计算，不是页面截图、字体栅格或设备验收。

正文 16 px、辅助文字 12–14 px 均按普通文字 **至少 4.5:1** 检查；小字不因“辅助”身份降低要求。标题也沿用此项目要求，不依赖大字豁免。阈值与计算依据见 [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 3. 字体排印

中文：**思源黑体 Source Han Sans SC**。英文与一般数字：**Inter**。模型格式、文件大小等辅助元信息：**IBM Plex Mono**。数值对齐采用等宽数字；省市名称使用中文字体，不展示建筑经纬度。

| 内容 | 桌面 字号／行高／字重 | 手机 字号／行高／字重 |
| --- | --- | --- |
| 页面标题 | 34 / 42 / 600 | 28 / 36 / 600 |
| 建筑标题 | 20 / 28 / 500 | 20 / 28 / 500 |
| 建筑介绍正文 | 16 / 28 / 400 | 16 / 26 / 400 |
| 导航、按钮、字段标签 | 14 / 20 / 500 | 14 / 20 / 500 |
| 城市、字段说明 | 14 / 22 / 400 | 14 / 22 / 400 |
| 英数辅助信息 | 12 / 18 / 400 | 12 / 18 / 400 |

- 城市或“未设置城市”采用次文字，错误说明采用语义文字，不用低透明度文本；城市未填不使用错误色。
- 不用伪加粗、超细中文、全大写长句、超宽字距或液晶字体。短模型格式保留其原本大小写。
- 正文每行以约 24–32 个汉字的舒适宽度组织；行高与区块间距分工清楚。
- 长建筑名称自然换行；文件名可断行，省市名称保持完整可读。气泡以城市标题和模型列表组织，不把整篇建筑介绍塞入气泡。
- 200% 文字放大时允许组件增高与布局折行，不把固定高度当作裁掉文字的理由。

字体尚未入库；需从官方项目取得对应版本与字重并保留许可文件：[思源黑体](https://github.com/adobe-fonts/source-han-sans)、[Inter](https://github.com/rsms/inter)、[IBM Plex](https://github.com/IBM/plex)。中文字体交付必须覆盖动态建筑名称与后台输入，不能仅包含十件样例的字。

| HUD 角标 | 长 8、线宽 1 | 长 6、线宽 1 |

手机顶部与底部另计系统安全区，不能拿安全区替代上述内边距。窄屏靠折行与纵向重排保住全部信息，不能通过缩小正文至 12 px 解决拥挤。

### 4.2 首页

- 桌面导航下为连续三维场景，背景延伸至导航下方。只有当前点位气泡，无常驻右栏或装饰数据面板。
- 手机品牌行与三个既有导航入口分两行；不新增折叠菜单，也不把入口缩成无文字图标。
- 气泡是点位的邻近信息，不能改成底部抽屉。先向右侧放置，再尝试左、上、下，以保持可读和减少遮挡为准；触边时沿边平移并保持指向点位的短连接线。具体锚点计算待实现验证，位置关系与完整按钮是验收要求。
- 手机城市气泡目标宽 280，最多为屏宽减 32；模型缩略图约 80×80、内边距 12、入口命中高至少 48。高度由城市标题和模型列表决定，多项时内部纵向滚动，不沿用单模型气泡固定高度。长标题允许增高，面积超限按 2.2 改实色。
- 极短视口或文字放大后，气泡最大高度为当前可用场景高减上下边距；气泡内部可纵向阅读，当前聚焦操作必须滚入可见区域。不得让整张气泡被页面裁切。

### 4.3 目录与详情

| 页面 | 桌面 | 手机／中间布局 |
| --- | --- | --- |
| 全部作品 | ≥1280 三列；768–1279 两列；封面 16:10 | <768 单列；名称、城市或“未设置城市”在图下方 |
| 详情 | ≥1024 左观看、右介绍；扣除 24 间距后，信息列取可用宽度 30% 与 300 中较大值，余下给观看区 | <1024 改单列；不把介绍压成窄栏 |
| 后台编辑 | ≥1024 双列约 60/40，间距 24 | <1024 单列，按任务顺序重排 |
| 后台列表 | 桌面保留表格的已有字段与操作 | 窄屏每件作品改信息块，全部字段与操作换行保留 |

详情单列顺序固定：返回入口 → 封面／远程观看区 → 现有控制条 → 名称、城市或“未设置城市”、作品点赞预留 → 建筑介绍 → 有内容的建模说明 → 评论预留。手机 390 宽下观看区初始约 340 高；尺寸随屏幕与内容校准，不能遮住系统安全区。

手机控制条位于观看区下沿，避开模型中心；320 宽或文字放大导致无法容纳时，移到画面外、改实色并分两行。放大查看为页内全视口观看覆盖层，仍是现有观看区的展开，不申请浏览器原生全屏权限，也不另开作品页面。

### 4.4 后台的单列顺序

名称 → 所在城市（选填，省份＋城市）→ 模型文件、封面 → 建筑介绍、建模说明 → 保存／预览／手动发布与返回。窄屏省市控件纵向排列；不提供地图选点和经纬度输入。仅选省份未选城市按未设置城市处理，省份是筛选条件。

列表的信息块保留 64 px 缩略图、名称和状态，下一行城市（可空）／格式，再放已有操作。操作文字自然换行，不形成横向滚动表格。登录表单沿用实色面板、顶部标签与 48 px 输入。

## 5. 组件规范

### 5.1 导航、卡片与按钮

- 当前导航用冷青文字和 2 px 短下划线共同表达；其他项用次文字。短线的过渡不影响布局尺寸。
- 作品卡片的画面与文字有稳定分区，16:10 预留空间，避免图片加载后把标题推开。整张卡片只有一个进入详情的链接目标，视觉按钮不制造重复键盘停靠点或嵌套链接。
- 只有当前选中卡片使用冷银短角标；常态用弱边界，无全圈发光。
- 当前任务只突出一个主按钮。主按钮始终冷青底、深色字；次按钮为实色底、正常文字与必要边界。玻璃内次操作若使用轮廓，必要边界采用 `#77A6A7`；取消／返回不与开始预览争抢亮度。
- 禁用是不可操作状态，不是整块内容降低透明度。限制原因保留可读文本。点赞预留不进入普通 Tab 操作序列，旁边明确标注“预留”；评论区不绘制可提交的假表单。
- 图标采用统一矢量线性风格、24 px 图形框、约 1.5 px 线宽；放入更大的命中区。图标按钮必须有可访问名称，不用 emoji 代替。

### 5.2 点位气泡

气泡是包含交互入口的非模态城市信息面板，不能按不可交互 tooltip 处理。最多显示一个；标题为城市名称，必要时显示所属省份以消除重名。内部每件已发布模型一行／项，显示封面、模型名与详情入口，每项只有一个链接目标；一座城市只有一件模型时结构相同。模型名允许两行，列表可滚动，关闭按钮始终可达且有清楚名称与足够命中区。

未设置城市的已发布模型不出现在城市气泡中，目录和详情显示“未设置城市”，不作为错误或未完成发布状态。地球没有城市但目录有模型时，提示“暂无可从地球探索的城市，请前往全部作品查看”。城市卡片加载失败就近提供重试，不能以预览繁忙代替列表读取错误。

图像区域即便在玻璃外壳内也使用不透明中性承托底；角标贴在画框选中边界，不描摹建筑轮廓。气泡 hover 保持区包含点位、短连接区域与面板，允许鼠标移入点击，不采用一离开点位就消失的规则。

### 5.3 表单与上传

- 标签在上方，必填标识有文字语义；占位文本不代替标签。草稿允许资料不完整，必填含义对应发布条件。
- 发布必填：模型文件、名称、封面、建筑介绍；所在城市与建模说明选填。城市用标准省市选择，支持清除；辅助说明“填写后可从地球城市卡片发现；不填仍可发布并在全部作品中查看”。省市字典加载失败保留已有值，无效城市编号显示字段错误，不自动清空。
- 字段默认边界 `#627D8B`，输入底 `#0D161E`；focus 使用统一焦点线；错误边界用 `#F08C82`，字段下说明放入 `#2A1B20` 错误底、文字用 `#F08C82`，保持已检查配对，不抖动。
- 文件区显示真实文件名、格式、上传状态。后端提供可用字节进度才显示百分比，否则只写真实阶段。不编造转换进度。
- “保存草稿”“检查预览”“手动发布”的业务语义固定；已发布元数据保存写“保存并更新公开内容”。文件替换受限时显示现有原因。
- 成功反馈不抢焦点；错误就近显示，失败后将焦点移至第一个需要修正的字段，不新增审批步骤或强制预览记录。

### 5.4 观看区状态

| 状态 | 画面与操作 | 焦点／文案规则 |
| --- | --- | --- |
| 未启动 | 正式封面＋开始预览 | 不自动连接、不加载完整模型到访客端 |
| 连接／模型准备中 | 保持观看区尺寸，显示后端真实阶段 | 不编造倒计时或百分比；重复启动不可用但焦点不丢失 |
| 可交互 | 远程画面＋已有复位／放大／结束 | 旋转与缩放输入只在观看区拥有操作焦点时接管 |
| 资源繁忙 | 封面与警示文字＋手动重试 | 不排队，不空闲后自动启动 |
| 断线／离线／失败 | 稳定错误说明＋已有恢复入口 | 断线后手动重试并重新申请；不自动重连 |
| 结束 | 回封面与开始预览 | 焦点回到可用的开始预览入口 |

状态更新只播报一次简短、完整说明，不逐帧或逐百分比打断阅读。此表不承诺远程渲染帧率、延迟或并发容量。

## 6. 三维场景规范

### 6.1 地球视觉与默认尺寸

- 海洋 `#0D1D27`，陆地 `#28454B`，地形亮面 `#8CA9AE`；网格 `#395962`，低对比、局部可见 2–3 条经纬弧线。
- 受光侧使用 `#54C8C1` 窄大气边缘，参考宽 6–10、透明度约 12–18%；它属于地球，不沿作品模型出现。无完整光环或轨道装饰。
- 桌面 1440×900 下球体直径参考 760，允许 740–780 的出图校准，占总屏高约 82–87%；中心略偏左，底部非关键边缘可裁 0–5%。当前位置与气泡必须完整可操作。
- 手机 390×844 下默认直径参考 405，锁定在 400–410 范围，接受横向合计约 2.5–5% 的裁切和气泡局部遮挡。其他手机宽度按 405/390 的宽度比例适配，不能把 405 生硬套到 320 宽手机。
- 上述比例指初始视图；用户主动缩放后的裁切可以增加，不能反过来把默认视图做得更大。中间布局以可用宽高约束球体，不遮导航和操作；球体的透视与机位校准标注为待实现验证。
- 布局起步值（待实现验证）：桌面球心在场景宽度 45%、高度 50%；手机在宽度 50%、高度 45%。中间布局直径取场景可用宽的 95% 与可用高的 90% 中较小值；其他桌面尺寸以 760、视口宽 54%、场景可用高 94% 中较小值起步。气泡避让优先保证操作完整，不移动其关联作品身份。
- 初始朝向中国大陆的主要城市分布；每座城市最多一个点，使用标准城市字典的中心坐标，只聚合已发布且设置了该城市的模型。中心点不代表建筑精确位置；不采用默认零坐标或省级示例点位。

### 6.2 地球交互建议值

以下全部为 **待实现验证** 的起步值，不是已实现能力或性能承诺。验证对象应包括鼠标、触摸板和真实手机。

| 项目 | 单一设计建议 |
| --- | --- |
| 拖拽 | 指针按下后跟手；累计移动超过 5 px 判定拖拽，抑制该次点击 |
| 灵敏度 | 位移 1 px 约对应 0.2° 水平／垂直相机旋转 |
| 俯仰范围 | 约 −70° 至 +70°；水平可连续旋转，不翻转地球 |
| 惯性 | 松手后允许约 150–300 ms 短时衰减；再次操作立即接管，具体按动效设计与实机结果校准 |
| 缩放范围 | 初始尺寸为 1.00，允许 1.00–1.60 倍；通过相机距离调整，保持城市中心与球体比例关系 |
| 鼠标／触摸板缩放 | 仅地球已获操作焦点且指针位于球体可操作区时接管普通滚轮，归一化一个常见刻度约改变 8%；Ctrl／Cmd 组合留给浏览器 |
| 手机输入 | 场景内单指拖动旋转、双指捏合缩放；导航、气泡及场景外区域保留页面滚动，系统缩放能力不能全站禁用 |
| 键盘旋转／缩放 | 地球操作区获焦时方向键每次约 5°，加／减号每次约 10%；限上述范围，离开操作区不接管 |
| 点位视觉与命中 | 可见点约 8 px；鼠标附近触发半径 18 px；触摸和键盘对应控件命中区至少 48×48 |
| hover 打开 | 稳定进入触发范围约 120 ms 后打开，气泡按动效设计分层入场约 280–380 ms，不触发地球镜头移动 |
| 离开关闭 | 点位、过渡区域、气泡均无指针且无键盘焦点时，等 200 ms 再关闭，约 160–240 ms 收起，按动效设计校准 |
| 点击／轻触 | 明确选中后触发约 500–800 ms 镜头调整，与气泡展开重叠；点击气泡外场景关闭，查看作品才进入详情 |
| 拖动时气泡 | 拖动成立即关闭指针触发的旧气泡，拖动结束后按当前位置重新触发；不在拖动途中切换气泡 |
| 背面与遮挡 | 球体背面和不可见点位不响应指针；键盘访问对应点位时先使其转到可见位置 |

### 6.3 模型观看的输入边界

模型观看保留既有旋转、缩放、复位和放大操作。远程画面获操作焦点后，方向键与加／减号可作为同类操作的键盘输入；具体相机步长由渲染团队针对模型尺度校准，建议起步约 5°／10%，标注待实现验证。不能将地球的地理俯仰范围直接复制为每个建筑的模型规则。

未启动时不捕获模型操作键；连接后也不拦截浏览器组合键。焦点离开观看区即停止输入接管。双指缩放与页面滚动的边界须用真实手机验证，不能用桌面封面缩放演示代替。

## 7. 焦点与键盘导航

### 7.1 全局规则

1. 页面进入后提供仅聚焦时可见的“跳到主要内容”入口；普通顺序为导航 → 页面主要内容与操作 → 后续现有内容。顺序跟随可见阅读顺序，不用正数索引重排。
2. Tab 前进、Shift＋Tab 后退；普通链接用 Enter，按钮用 Enter／Space。方向键只在明确的场景操作区或字段原生语义内接管，不覆盖页面通用滚动。
3. focus 立即显示，采用 2 px 深色间隔＋2 px 焦点线；不能被圆角、裁切、透明图片或浮层遮掉。
4. 项目要求聚焦控件和焦点线完整可见；固定导航、气泡、控制条、软键盘出现后要滚动或移动到可见位置。这比 WCAG 的最低“不得完全遮挡”要求更严格，不能把更严格的项目目标误称为最低标准。[W3C 焦点不被遮挡说明](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)
5. 页面导航完成后聚焦主标题或主要内容起点；浏览器返回尽量恢复到原点位／作品卡入口及滚动位置，入口已不存在时回相应列表标题。不得通过恢复页面自动申请预览会话。
6. 保存成功、网络状态和普通提示不抢焦点。因状态切换而移除当前按钮时，将焦点交给同位置的下一步有效操作，不能落到页面最上方。
7. 表单与中文输入法组合期间不截获方向、加减或 Esc；不禁用系统缩放、浏览器导航和辅助技术组合键。

### 7.2 地球与气泡

- 地球操作区有清楚名称和简短操作说明，是一个可进入、可离开的焦点停靠点；Tab 可随时离开，不能锁在画布中。
- 城市点位按接口返回的稳定顺序进入键盘序列；进入城市气泡后依次访问其已发布模型，不要求先用方向键找到屏幕坐标。
- 聚焦城市点位时显示气泡；背面／视口外城市先转至可见位置，焦点身份保留在该城市。草稿、下架模型与无城市模型不能进入气泡序列。
- 点位气泡不锁焦点。顺序为当前城市点位 → 气泡关闭 → 模型列表各详情入口 → 下一城市点位；Shift＋Tab 反向。气泡内有焦点时保持打开，不启动离开关闭计时；列表中的焦点项自动滚入可见范围。
- Enter／Space 在点位上只打开或保持气泡，不直接跳详情；在“查看作品”上激活才进入详情。
- Esc 或关闭按钮收起气泡并把焦点回当前点位；本次保持焦点不会立即重开，离开再聚焦或再次激活才打开。
- 指针悬停本身不移动键盘焦点，不关闭正在进行键盘操作的气泡。

### 7.3 详情、展开观看与反馈

- 详情顺序：返回 → 开始预览或当前有效恢复操作 → 观看区及已有工具 → 建筑介绍与预留说明。正文块不逐段制造 Tab 停靠点，预留评论与点赞不是可提交功能。
- 点击开始预览后保留启动位置焦点并播报连接阶段；等待时该入口可标识不可重复激活，但不能因替换节点让焦点丢失。
- 出现繁忙／断线后让同位置的手动重试可用；不自动聚焦重试、不自动申请新会话。用户结束后聚焦开始预览。
- 放大查看统一为页内模态观看覆盖层：打开后聚焦“恢复常规查看”，Tab 与 Shift＋Tab 仅在覆盖层内循环；底下页面不可操作，覆盖层有明确的作品名称。
- Esc 或“恢复常规查看”关闭覆盖层，焦点回原放大按钮；这不会结束预览。结束预览仍是独立既有操作，结束后覆盖层保留封面，恢复按钮仍可用。
- 覆盖层焦点管理依据 [WAI-ARIA 模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)，普通点位气泡不采用模态规则。

### 7.4 后台、输入与校验

- 账号、密码、标准省市选择、文件选择、长文及现有操作依可见顺序进入键盘序列；文件选择器关闭后回原文件按钮。
- 发布或保存校验失败：保留所有已输入内容，聚焦第一个错误字段，字段名称、必填含义与错误原因可被读出。编辑中不每按一个键就重报错误。
- 多行建筑介绍与建模说明中的 Enter 用于换行，不提交或发布。发布必须由用户明确激活对应按钮。
- 标准省市选择须支持键盘，省份切换时清除不再适用的城市；省市均未选或只选省份时 cityId 为 null。清空已有城市后，已发布模型仍在目录中；保存后移出原城市气泡，原城市无模型时移除点位。
- 保存、发布和下架后优先保留当前作品及其操作位置；操作消失时聚焦该作品名称，作品被移出当前视图时聚焦列表标题。
- 登录失效和权限结果按真实认证流程呈现；本规范不新增账号权限、密码恢复或访客登录模块。

## 8. 动效规范

本节于 2026-10-18 同步为复杂动画方案。完整分镜、时长、手机适配、打断与清理规则统一采用 [动效设计 v1.0](动效设计v1.0.md)。

首期制作首页空间入场、点位与镜头联动、封面到详情的连续转场；卡片、观看区放大恢复和后台状态提供配套反馈。AI 助手按完整组件挂载规划，面板反馈与动画由组件提供，主站通过公开配置协调深色主题和位置。主站时间轴采用 GSAP + @gsap/react，Flip 处理选定转场；Three.js / Fiber 负责实际三维场景。

跟手拖动后允许动效文件约定的短时惯性，用户再次操作时立即接管；快速重复输入不堆积动画队列。手机保留核心动画，通过幅度和渲染成本调整适配；正常模式不统一简化为淡入淡出。

系统减少动态偏好按动效文件提供替代呈现，焦点立即可见。动画时长不表示上传、模型准备或网络连接耗时，真实状态必须独立反馈。

## 9. 封面统一出图规范与流程

### 9.1 主线与标准

**正式内容以统一出图规范、逐件重新出图和真实渲染复核为主线。** 现有封面可作来源与过渡，不代表已完成统一出图。

AI 基于模型、元数据与已有资料辅助整理文字及自动出图；无法核实的建筑身份、历史和城市不推断为事实，城市可留空。首次演示缺图可以使用明确占位，正式交付逐件替换／复核；正式模型封面仍来自真实渲染，不以 AI 重绘建筑替代。高斯渲染环境未就绪时记录待办，不阻塞页面动画演示。

| 项目 | 正式要求 |
| --- | --- |
| 源内容 | 团队真实 GLB 或高斯 PLY；保持几何、材质、颜色来源可追溯 |
| 母版 | 2400×1500，16:10，sRGB；优先透明背景 PNG，保留母版 |
| 网页衍生图 | 960×600 WebP，保留透明；详情需要更大图时使用母版或对应较大衍生图 |
| 构图 | 完整建筑／采集范围，不拉伸；主体宽高均不超过画幅约 90%，按最长方向取景，允许长条模型自然留白 |
| GLB 机位 | 俯视约 35°、允许约 ±5° 校准；方位选能表达建筑特色的一侧，记录相机与复位参考，不统一强行摆成同一正面 |
| GLB 光照 | 中性灯光，约 6500 K 作为起点；有柔和明暗，无青色染光和过曝白边 |
| 高斯模型 | 使用团队确认的高斯渲染器，保留真实采集外观；透明导出、背景和曝光能力须按工具确认，不假定可像 GLB 一样重新打光 |
| 页面承托 | 透明图像落在固定实色 `#20272B` 上，玻璃场景不透入图像；不新增厚照片框来代替出图 |
| 色彩限制 | 浅石材可分层、木构仍暖、绿植不与冷青粘连；不靠全图青滤镜、黑罩或 AI 重绘建筑统一风格 |
| 边缘 | 在 `#20272B` 与 `#080D12` 上都检查树叶、檐口、细柱及透明边，不能有白边、黑边或缺失构件 |

图像承托底是固定的中性校色底层；“过渡实色画框”专指保留未规范化原图时额外明确收边的临时容器。正式透明封面仍有承托底，但不依赖临时照片框或深色罩层融合场景。

### 9.2 执行流程

1. **登记来源**：建模团队确认模型版本、材质、使用范围和实际建筑资料。现有长城扫描色直接保留；若团队认为纹理颜色异常，先处理源资产，不由 UI 私自改色。
2. **建立两类样张**：先重出浅色院落与绿色长城，校准曝光、构图、透明边与统一暗底；图像外同时摆放冷青操作色和冷银角标作定性复核。
3. **记录出图配方**：记录渲染工具版本、相机、背景、光照／曝光与母版尺寸；记录属于制作资料，不增加后台业务字段。
4. **逐件出图**：GLB 按统一配方适配机位；高斯资源使用正确渲染流程正式出图，不把采样点云投影当作正式高斯封面。
5. **检查母版**：以 100% 查看边缘和纹理，以目录尺寸查看识别度，再检查手机气泡内的小图是否可辨认。
6. **导出并关联**：保留 PNG 母版，导出网页衍生图，用作品的实际关联标识命名并记录对应关系；不把长文件名当作建筑展示名称。
7. **替换并复核**：使用最终页面的规定中性底、实际主按钮和冷银角标复核。此项留待实现完成，不能由生成的研究板替代。

该流程是内容制作与视觉验收规范，不新增网站的发布硬校验；管理员手动检查和发布规则仍按既定业务执行。

### 9.3 实色画框过渡的触发与退出

仅当正式重出图尚未交付，且已有经过团队认可的真实封面可用时采用过渡画框，包括：原图自带亮天空、透明边缘尚未修正或当前封面视角未统一。过渡容器采用实色 `#20272B` 和普通边界，完整放图，不能伪装成无缝暗场景。

过渡项在内部资产记录中列出作品、原因、负责人和替换状态；正式图通过第 9.2 节复核后退出。不得以进度为由将 AI 合成建筑或近似点云图直接升级为正式封面，也不新增公开状态字段。

内容工时仍按前序估算：GLB 首次规范配置约 2–4 小时，流程就绪后每件重出与复查约 30–60 分钟；约十件可预留 1–2 个工作日。上述不含模型修复、高斯流程准备或多轮返工，不作为确定排期。高斯正式封面工时待工具与样张落实后估算。
