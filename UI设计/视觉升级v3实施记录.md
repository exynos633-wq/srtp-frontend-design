# 公开端视觉升级 v3 · 墨·纸·朱砂

实施日期：2026-10-22。依据：用户确认的 [视觉方向 v3（墨·纸·朱砂）](视觉方向v3（墨·纸·朱砂）.md) 与图片 A 版式（目录等距四列、详情左图右文），以及本轮“继续进行 UI 优化”的指示。

本文只记录实施结果与验证范围，不替代设计规则；色彩、版式和动效规则以视觉方向 v3 为准。后台继续采用 [视觉规范 v1.0（深色）](视觉规范v1.0（深色）.md) 的布局与业务规则，只共享墨／纸中性色 token。

## 1. 实现范围

- 公开端全站换为墨黑底、纸白文字、朱砂引导色；`tokens.css` 更新 v3 色板，新增 `accent-line`／`accent-text`／`line-strong` 语义 token 与 `--page-inset` 对齐变量。
- 公开导航：实色墨黑、1 px 发丝下边线，取消玻璃、圆角框与滚动收拢；当前项与指针／焦点共用 1 px 朱砂短线，滚动时导航下沿显示细进度线。手机保留品牌行与三个文字入口两行实色布局，三个入口按可用宽度均分。
- 首页：保留地球展厅、开场分镜、城市点位／气泡／镜头联动；地球换为墨灰陆地与纸白大气边缘，城市点为朱砂实点，悬停／选中使用放大与纸白短环。标题列、场景标签、拖动提示与 Mock 信息统一到同一内容对齐线。
- 目录：桌面 1280 起等距四列，1024–1279 三列，768–1023 两列，手机单列；卡片按“封面 → 编号／作品名 → 城市（前置朱砂小点）”阅读，没有第一张放大的主次网格。整卡只有一个详情链接，悬停保留倾斜、景深、指针展陈光与封面轻放大，阴影为中性黑。
- 详情：≥1024 为左观看区约 8 列、右信息列约 4 列，间距 40；信息顺序为眉题／编号 → 作品名 → 城市 → 建筑介绍 → 建模说明（有则显示）→ 作品信息 → 评论／点赞预留。手机按第 7.2 节单列顺序重排；开始预览仍在观看区内，覆盖层放大沿用同一实例与视角。
- 交互层：新增纸白指针展陈光与伴随环（仅精细指针、非减少动态）、卡片多层视差、导航跟随短线、点位纸白短环与连接线、封面到详情连续转场。所有新增交互都在减少动态下关闭，业务状态与 DOM 顺序不变。
- 状态与占位：公开端加载／繁忙／错误／空状态改为实色墨面与发丝线，不用玻璃、胶囊或彩色光；Mock 标识、演示封面占位和“非真实接口”提示继续明确呈现。未新增搜索、关于、文件大小、三角面数、统计或排名信息。

## 2. 本轮 UI 优化（2026-10-22 第二轮）

- 统一内容对齐线：新增 `--page-inset`，让公开导航、首页标题列、场景标签、拖动提示、目录／详情页内容与页脚在 1440 及更宽视口使用同一条左右对齐线；宽度超过 1560 时跟随内容列居中。导航移除 12 px 顶部留白与页面内多余边框，高度回到 64 px。
- 手机导航：三个入口改为均分可用宽度，朱砂短线落在当前项文字下方并居中，宽度限制为短线而非整条导航装饰。
- 反馈颜色回到 v3：指针环由朱砂改为纸白；城市点位悬停环由朱砂改为纸白；导航、点位与状态仍只在真实交互／状态时出现颜色。
- 文字层：详情作品名桌面 52 px、区块标题 22 px、建筑介绍 16 px／1.8；详情图文间距 40 px；首页手机主标题下限 36 px。
- 目录卡片：城市行补 4 px 朱砂小点；桌面箭头由带框圆形收为无框短箭头（触屏保留细框），悬停时边框升为 `line-strong` 并出现中性黑阴影；封面轻微放大与倾斜景深保留。
- 加载／繁忙／错误等公开状态去掉旧版蓝黑与模糊底，统一为 `ink` 实色面与 2–4 px 圆角。

环境：macOS、本机 Google Chrome 155、Node v24.19.0（按 `engines` 使用，未下载浏览器、未改依赖与锁文件）；`frontend/` 内执行。

| --- | --- |
| `npm run typecheck` | 通过 |
| `npm run lint` | 通过 |

| `CI=true npm run test:e2e -- --workers=2` | 115 条 Chrome E2E 全部通过（约 4.1 分钟），含 v3 布局、指针层、减少动态与既有观看／转场用例 |
