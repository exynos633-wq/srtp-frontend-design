## 1. “高级感”的 10 条可执行规律

> 每条固定四段：**现象 → 证据 → 手法（参数） → 在本站怎么落地**。参数取“可复制的起点值”，不是审美唯一解。

### 规律 01 · 深色底上先叠“光”，再叠“色”

**现象**：高级深色界面不靠更多颜色拉开层级，而靠 2–3 层**低强度白光/冷光**叠加；光层通常是大半径 radial-gradient + `lighten/screen`，跟随光标或极慢浮动。颜色本身几乎不超过 2 个色相。

**证据**
- Linear 首页的光层规则 [A]：`.MwJdiW_glow{--glow-opacity:.04;background:radial-gradient(circle, rgba(255,255,255,.04) 0%, transparent 50%);mix-blend-mode:lighten;width:400px;height:400px}`；另有 `radial-gradient(circle,#ffffff14 0%,#0000 50%)`、800×320 的椭圆光。元素均 `position:absolute; top:0; left:0; transform:translate(-50%,-50%)`，以锚点为中心（这类 400px 光点通常由脚本跟随光标，位置属客户端实现，静态抓取看不到）。
- Raycast 弹窗外壳 [A]：`radial-gradient(85.77% 49.97% at 51% 5.12%, #5056eb1c 0%, #dee2ff14 45.83%, #f1f2ff05 100%)` 叠 `#00000070`，1px `#ffffff14` 边。
- Stripe 首页渐变是**多层渐变状态交叉淡入** [A]：`.stats-animation-gradient__gradient{opacity:0;transition:opacity var(--stats-section-transition-duration) var(--stats-section-transition-timing-function)}`，其中 `duration:1.2s`、`timing-function:cubic-bezier(0.65,0,0.35,1)`，`prefers-reduced-motion` 直接归零。

**手法**
- 光层尺寸 400–900px，alpha **0.02–0.08**，`mix-blend-mode: lighten`（或 `screen`）；
- 同屏最多 2 层；一层固定（构图光），一层跟随光标（交互光）；
- 跟随用 `transform: translate3d()` + 每帧 `lerp(current, target, 0.08–0.12)`，**不要**改 `background-position`；
- 不要整页 `filter: blur()` 做“氛围”，成本高且糊掉文字。

**本站落地**
- `GlobeExperience.module.css .stage` 已有两极暗角，但**没有发光层**。在地球画布后加一层 900–1100px 椭圆光：`radial-gradient(ellipse, rgb(198 226 230 / 5%) 0%, rgb(84 200 193 / 4%) 35%, transparent 70%)`，`mix-blend-mode: screen`，固定不随时间动。
- 交互光 400px 只给**首页地球区 + 详情封面区**（`lighten`，alpha ≤ .06）；目录页只保留顶部 1 层光，避免 10 张卡片都在发光。
- 详情页顶部加 1px 渐变边缘光（`linear-gradient(90deg, transparent, rgb(198 226 230 / 18%), transparent)`），比阴影更“贵”。

### 规律 02 · 颗粒 + 极细边，是最便宜的高级感开关

**现象**：高级站几乎都有 noise/grain overlay（把纯色平铺变成材质）和 1px 半透明描边（代替重阴影）。这是**静态都能感知**的“贵”，不依赖动画。

**证据**
- Linear [A]：`.SPbJba_grain{opacity:.9;mix-blend-mode:overlay;background-size:256px 256px}`、`.SPbJba_grainSubtle{opacity:.6}`，颗粒层 `inset:1px` 盖在截图/插画上；页面里 `grain` 出现 18 次。
- Raycast [A]：卡片边 `1px solid #ffffff0f`、弹层 `#ffffff14`；玻璃面板 `backdrop-filter: blur(24px)` / 弹窗 `blur(32px)`。
- 技术做法 [B]：[CSS-Tricks《Grainy Gradients》](https://css-tricks.com/grainy-gradients/) 用 SVG `feTurbulence type="fractalNoise" baseFrequency="0.65" numOctaves="3" stitchTiles="stitch"` 生成噪声。

**手法**
- **全局只放 1 张** 128–256px 噪声 tile 平铺（raster 或 `feTurbulence` 转 data URI），`opacity: .02–.04`，`mix-blend-mode: overlay`，`pointer-events:none`；
- 深色底（< #101010）用 `.02` 起步，浅色底可到 `.05`；`background-size: 256px` 比 64px 更不“电视雪花”；
- 卡片：`border: 1px solid rgb(255 255 255 / 8–12%)` + `box-shadow: inset 0 1px rgb(255 255 255 / 6%)`（顶边受光）；
- 不要把 noise 放进每个卡片各自一层（合成层爆炸），也不要让颗粒随滚动重绘。

**本站落地**
- 在公共布局挂一个 `position: fixed; inset: 0` 的颗粒层（`::after` + data URI 噪声，`opacity: .025`，`z-index` 在内容下方、画布上方或最顶层取决于是否要作用于地球：建议**只覆盖 DOM，不盖 canvas**，避免纱窗感）。
- 目录卡片与气泡边框从实色 `var(--color-line)` 改为 `rgb(255 255 255 / 10%)`，hover 到 `16%`；顶边保留 1px 内高光。这项工作与动效无关，但会直接提升“精致度”。

### 规律 03 · 光标即光源：spotlight / shine / flashlight

**现象**：高级站的高光不是固定的，而是被光标“点亮”：一条 1px 描边被 radial mask 局部照亮，或卡片表面被一个圆形径向光照亮。

**证据**
- Linear 的 shine 层 [A]：`mask-image: radial-gradient(ellipse var(--shine-beam-length) var(--shine-beam-length) at var(--mask-x) var(--mask-y), #000 0%, #0009 30%, #0003 50%, #0000 70%)`，`--shine-beam-length: 200px`，元素是 `1px solid` 边框；光标/锚点位置通过 `--mask-x/--mask-y` 传进 mask（HTML 里已出现 `0/20%`、`100%/0%` 等锚点值）。
- Raycast 卡片 [A]：`:after` 铺 `radial-gradient(100% 100% at 50% 0%, var(--grey-700), var(--grey-600) 150%)`，hover 时 `opacity:0→1`，`transition: opacity .15s ease-in-out`。
- 原型参考 [B]：[rauno.me/craft/flashlight-tabs](https://rauno.me/craft/flashlight-tabs)（光标照亮 tab 的同类做法）。

**手法**
- mask 半径 **160–240px**；stops 用 `0% / 30% / 50% / 70%` 对应 alpha `100% / 60% / 20% / 0`——这个衰减比线性渐变更像光；
- 每帧只更新两个 CSS 自定义属性（`--x/--y`），**不要**改 `clip-path`、不要触发 layout；
- 触摸设备与 `prefers-reduced-motion` 关闭；只在 `(hover:hover) and (pointer:fine)` 生效；
- 光带（1px 边框）比整面高光更克制，适合展览语言。

**本站落地**
- `WorkCard.module.css` 封面 hover：加一层 `mask-image` 的 1px 描边光（半径 180px），与现有 180ms 边框变色并行；标题不动。
- `CityBubble` 与详情工具栏按钮：半径 120–160px，只照边框，不照背景。
- 光标跟随用 `pointermove` → rAF 写 CSS 变量，**不要**每帧 `setState`（v2.0 §9 已有同样约束）。

### 规律 04 · 入场三件套只给一级标题：遮罩 + 模糊 + 位移

**现象**：标题揭示常见“外层 `overflow:hidden` + 内层 `yPercent 110→0`”，更贵的一档会在同段叠一个 `blur(10px)→0`。模糊是**小面积、短时间**的，不是段落级。

**证据**
- Linear 标题行初始态 [A]：`opacity:0; filter:blur(10px); transform:translateY(20%)`（内联样式），进入时由脚本补间归零。
- Vercel [A]：`letterReveal` `0.5s ease-out`，关键帧到 `opacity:0; filter:blur(4px); transform:scale(1.3)`（“散开消失”式揭示）；`invisibleReveal` `1s` + `delay 1s`；两者都有 `prefers-reduced-motion` 直接终态。
- Raycast 弹层 [A]：`animation:.15s cubic-bezier(.16,1,.3,1) contentShow`，关键帧 `translate(-50%,-48%) scale(.96)` → 终态；**150ms** 是“快而准”的量级。

**手法**
- 主标题：`blur 8–10px → 0`、位移 `12–20%`（或 8–16px）、`opacity 0→1`，总 **500–620ms**，`power3.out`；
- 副标题/描述：只做 `opacity + 8–10px`，**340–420ms**；
- 退出一律比进入快 20–30%；`blur` 只给文字或小图标，不给视频、画布、整屏；
- 中文不要逐字（断行与字距会散），逐行已经是上限。

**本站落地**
- v2.0 §4 已有两行标题 `yPercent 110→0`（560ms、stagger 120ms）。升级只需给内层叠 `blur(8px)→0`，压在**前 300ms**，总时长 +80ms 以内；保留现有的 1.35s 总预算。
- 目录页标题维持纯位移；详情页信息列维持 `y10 + opacity`，不加 blur（列表加 blur 会显脏）。

### 规律 05 · 滚动即相机：pin + 进度变量 + 慢速

**现象**：高级产品/空间站把滚动映射成**相机或时间轴**：段落被钉住（sticky/pin），滚动进度驱动视频帧、相机角度或文字出现，而不是“进入时播一次”。共同点是**慢**：镜头移动幅度小、被钉住的段落长。

**证据**
- Apple Vision Pro [A]：26 个 `<video data-inline-media>`，播放关键帧写成 `data-inline-media-play-keyframe='{"start":"t - 100vh","end":"b"}'`、预加载 `load-keyframe {"start":"t - 200vh","end":"b + 100vh"}`、复位 `reset-keyframe` 带 `"disabledWhen":["reduced-motion"]`；外层是 `sticky-container` / `sticky-element`。
- The Pendragon Cycle [B]：Merlin Studio 案例原话“**Scrolling is the camera**”“slow, deliberate moves”“treat each section like a shot”；技术文章确认 Three.js + 自定义 shader + 粒子 + 资产流式加载。
- Stripe [A]：`@supports (animation-timeline: scroll())` 内启用 CSS 滚动驱动动画（`timeline-scope`、`animation-timeline:--dialog-snap-timeline`），不支持时走 JS；CSS 滚动驱动的 [MDN 页面](https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timeline) 标注 Baseline 于 **2026-10** 可用。

**手法**
- pin 高度 = 内容屏数 × **1.5–2.5**；GSAP `scrub: 0.6–0.8`（有阻尼，不是 1:1）；
- 相机每屏移动 **≤ 3–5%**（距离 ±3%，角度 ±2–3°）；过大就不是“高级”而是“晕”；
- 一律提供 `prefers-reduced-motion` 的**终态直达**（Apple 用 `disabledWhen` 明确关掉 reset/播放）；
- 能用 CSS `animation-timeline` 就不上 JS，作为渐进增强。

**本站落地**
- 首页地球：滚动 0–60vh 内做 `纬度 ±2°`、`距离 ±3%` 的相机微动，**不 pin**（直接映射进度，滚动回退可逆）；与现有拖拽/惯性冲突时，用户输入立即接管。
- 详情页观看器：进入时 pin **70vh**，完成“封面 → 画布”一次推入（用 GSAP ScrollTrigger，`scrub:0.7`），返回不重播；这是全站唯一新增的“仪式感”时刻。
- 不要做多屏长叙事（3D 资源与帧预算都不允许）。

### 规律 06 · 常驻微动态：低频、低幅、可暂停

**现象**：高级站也有“一直在动”的元素（星点、呼吸光、漂浮），但**数量少、幅度小、周期长**，并且页面不可见时停。

**证据**
- Vercel [A]：`twinkle` 关键帧 `opacity .2 → 1 → .2`；`float-y` `translateY(0) → -6px → 0`；`drawPath` 用 `stroke-dashoffset` 从 `--start-offset` 到 `--end-offset`。
- Linear [A]：网格点 `grid-dot-*-upDown` 用 `steps(1,end)`、**2800ms** 无限循环、透明度 0.3——用“阶梯”而不是平滑，反而更像仪表盘。
- Apple [A]：视频 `loop`，但播放/暂停由滚动关键帧控制，并非永远在播。

**手法**
- 呼吸：`scale 1 → 1.12`、`opacity .6 → 1`、**3–5s**、`sine.inOut`、yoyo、随机 delay `0.2–1s`；
- 闪烁：`opacity .35 → .9`、**2.4–5s**，用 `steps()` 或 `sine` 都可以，但不要 `linear`；
- 同屏同时动的元素 **≤ 12 个**；超出就只给“当前选中/邻近”的元素；
- `document.visibilitychange` + `IntersectionObserver` 暂停；`prefers-reduced-motion` 全停。

**本站落地**
- 现有云层漂移保留；新增：城市点呼吸（选中点更亮，其余 0.6 基线）、背景星点 twinkle、轨道虚线极慢漂移（60–90s）——**三选二**，不要三样齐上。
- 所有常驻动画挂在画布外的 DOM 或 Three 对象上，不写 React state；首屏结束前不启动。

### 规律 07 · 物理感：跟手、可打断、spring 收尾

**现象**：高级交互的“手感”不是更多弹跳，而是**立即响应 + 从当前状态接管 + 轻微过冲**。手势与动画是一体的：拖动 1:1，松手才交给弹簧。

**证据**
- rauno [B]：称“可打断（interruptability）”是真实世界交互的核心属性；拖拽应用保留“掷出的动量与角度”；手势阈值应区分“轻量动作立即触发”与“破坏性动作等手势结束”。
- [Josh Comeau《A Friendly Introduction to Spring Physics》](https://www.joshwcomeau.com/animation/a-friendly-introduction-to-spring-physics/) [B]：spring 的两个核心参数是 tension（库中常叫 `stiffness`）与 friction（`damping`）；**高摩擦 = 丝滑不弹**，spring 不只用于 Q 弹。
- Raycast toast [A]：`0.4s` 自定义 `linear()` 缓动，曲线在 ~65% 处到达 **1.0727** 再回落 1（轻微过冲的“弹簧感”），`delay .5s`。
- Arqui9 光标 [A]：`gsap.to(cursor, {x,y,duration:0.3,ease:"easeOut"})` 跟随；hover 时 `scale` 过渡 `0.4s inOutQuart`。

**手法**
- 交互反馈 **100–300ms**；叙事段才允许 >1s；
- spring 起点：`stiffness 300–420`、`damping 30–36`、`mass 1`，过冲控制在 **≤3%**（气泡/菜单够用，不需要 Q 弹）；
- 关闭/取消从**当前值**开始 tween，不排队、不回到起点；
- 光标光晕 `lerp 0.1–0.15`；磁性按钮位移 ≤ 4–6px，不要整块飞过去。

**本站落地**
- v2.0 的 `--ease-out`（cubic-bezier 0.23,1,0.32,1）已接近“快出慢收”。升级点：气泡/菜单/面板改用 spring 或带 1.5–2% 过冲的 `linear()`，替换现在的纯 cubic-bezier；
- 光标光晕（若做）300ms `easeOut` 跟随即可，不要做磁吸按钮（展览语言不需要）；
- 保持 v2.0 的“任何输入立即接管”；惯性参数（90° 限幅、200–600ms）保留。

### 规律 08 · 连续转场：共享元素 + 空间一致性

**现象**：卡片 → 详情 → 观看器，高级站用**同一元素/同一位置**连续过渡：元素从原位置长出来，而不是新页面淡入。视线不跳，空间关系被记住。

**证据**
- rauno [B]：“空间一致性”案例——从 Dynamic Island 点击应用，应用从 Island 下方滑出；从图标启动则从图标位置出发；位置决定了用户对“东西从哪来”的理解。
- Arqui9 [A]：用 GSAP `Flip.getState / Flip.from({simple:true})` + `ScrollTrigger.create({scrub:true, animation:flip})` 让元素在容器间翻转，同时 `rotationY: -25` 与滚动同步；主题色也随 ScrollTrigger `onEnter` 切换。
- Apple [A]：`sticky-element` 把同一段视频钉在视口，内容在其上滚动——也是“空间连续”的一种。

**手法**
- Flip 进入 **600–650ms** `power3.inOut`，返回 **300–400ms**；`transform-origin` 必须一致；
- 交接期间不要让背景亮度变化（会打断连续性）；
- 新元素从原元素位置 `scale(.96)→1` + fade，而不是纯 fade；遮罩只用于“离开旧页面”的那一层；
- 结束清理临时内联样式（Arqui9 用 `clearProps`）。

**本站落地**
- v2.0 已有封面 Flip 620ms + 遮罩 180ms；升级：**观看器从封面“模型所在的一角”推入**（记录封面矩形与画布目标矩形做插值），返回 320ms；目录→详情的封面路径保持。
- 目录滚动位置恢复已有；再补“返回时焦点元素与光层位置连续”（现在光层是静态的，天然连续）。

### 规律 09 · 排版质感：字与底的光互动，而不是“字在动”

**现象**：高级站的大标题常与背景渐变**混合**（`mix-blend-mode`），光扫过时文字亮度跟着变；动效只是很小的字距/透明度变化。逐字动画在中文字体上几乎总是减分。

**证据**
- Stripe 首页 [A]：标题做**双层**——背景层正常排，前景层 `h1.hero-section__title--foreground{position:relative;z-index:2;mix-blend-mode:hard-light;color:rgba(0,14,255,.5)}`、`.hero-section__title-main{color:#2d2564}`；叠在渐变上时文字会“吃”底色。
- Linear [A]：标题行只做遮罩 + 模糊（规律 04），没有逐字。
- rauno [B]：[Contrasting Aesthetics](https://rauno.me/craft/contrasting-aesthetics) 讲的是“克制地混搭材质”，而不是单一极简——对深色展厅的启发是“光/玻璃/颗粒可以混，但每种只占一个层级”。

**手法**
- 标题叠一层 `mix-blend-mode: overlay`（深色底）或 `hard-light`（有彩色底），透明度 0.10–0.18；底层光层缓慢移动（±5%、8–12s）即可产生“呼吸”；
- 字距只在进入时变一次（`.18em → .22em`、400ms），不要 hover 时反复变；
- shimmer 只用于“正在加载/渲染中”，不要给标题加常驻流光；
- 中文避免逐字、避免描边字、避免渐变文字。

**本站落地**
- 首页大标题可加一层银青渐变 + `mix-blend-mode: overlay`（alpha .10–.15），让地球光/星光扫过时标题有轻微亮度变化；不要加文字阴影。
- eyebrow（`A NEW PERSPECTIVE`）进入时字距 `.18em→.22em` 一次，400ms；目录页标题不做 blend（背景干净，做了反而脏）。

### 规律 10 · 预算：一次性叙事 ≤1.5s、常驻 ≤2 组、其余只响应

**现象**：高级 = 克制。预算集中在 1–2 个“哇”时刻；其余都是短反馈。多数高级站**故意不动**的地方比动的地方多。

**证据**
- Merlin Studio 案例 [B] 原话：“the temptation is to animate everything, and most of the work was **deciding what stays still**”；Pendragon 的 3D 没有无意义旋转/粒子爆炸，“每次 3D 元素都为叙事服务”。
- [animations.dev](https://animations.dev/) [B]：课程卖点就是“**bad easing or duration can ruin an otherwise great animation**”“知道该用哪个 easing、时长多少、哪些属性才高性能”。
- Apple [A]：关键帧 + `disabledWhen:["reduced-motion"]`，减少动态不是可选项。

**手法**
- 每页最多 **1 个**仪式感时刻（首页开场 / 详情推入），其余是 100–300ms 响应；
- 新增动画必须**替换**一个旧动画，或写清“目的”（引导/反馈/空间连续性），否则不做；
- `prefers-reduced-motion` 与 hover 门控随动画一起交付；动画永远不是可用性前置条件；
- 帧预算：DOM 动效只做 `transform/opacity`；[MDN 动画性能](https://developer.mozilla.org/en-US/docs/Web/Performance/Animation_performance_and_frame_rate) 明确 `transform/opacity` 走合成层，`filter/backdrop-filter` 不是。

**本站落地**
- v2.0 开场 **1.35s 已接近上限**；升级只加“光/材质/微动”，不动时长结构。
- 全站新增的“哇”时刻只有一个：详情页观看器推入。首页升级靠光和颗粒，不靠更多动作。
- 验收时记录帧时间与设备（v2.0 §10 已有要求，继续执行）。

## 2. 深色空间类站点案例拆解（Awwwards 获奖为主）

### 2.1 Arqui9 Visualisation · 建筑可视化（Awwwards SOTD，2025-07-25）

- 站点：<https://www.arqui9.com/>；奖项：[Awwwards SOTD](https://www.awwwards.com/sites/arqui9-visualisation)；制作方案例：[N4 Studio《Arqui9》](https://www.n4.studio/work/arqui9)。
- 背景：伦敦 3D 创意机构，做建筑可视化与电影感影像，客户含 Zaha Hadid Architects、Ferrari、Mercedes-Benz。N4 的案例文章写明挑战是“全屏视频、高分辨率渲染、电影感序列，不能重”。
- 技术栈（源码实测 [A]）：GSAP **3.12.5** + ScrollTrigger + CustomEase + Flip（CDN）、Lenis **0.2.28**、Swiper、Lottie；HTML 中 `data-animation="in-view / scramble / in-view-button"`、`data-button-animation="text / line / icon"`、`data-cursor-true="true"`、`data-theme="dark / invert"`、157 处视频引用。
- 具体手法（内联脚本原值 [A]）：
  - **滚动刮擦视频**：`gsap.timeline({scrollTrigger:{trigger,start:"top top",end:"bottom bottom",scrub:true}}).to(video,{currentTime:video.duration,ease:"none"})`；视频用 IntersectionObserver `rootMargin:"500px"` 懒加载，移动端用 100ms 延迟 `play()` 再 `pause()` 解锁。
  - **开场 skew 缩放**：背景视觉 `width:100vw;height:100vh;skewY:0` → 桌面 `32vw×26vh`、`skewY:2`，滚动驱动；退场 `duration:0.6, ease:"inOutQuart"`。
  - **Flip + 3D**：元素在容器间 `Flip.from(state,{simple:true})`，同时 `rotationY:-25` 与滚动同步；`clearProps` 清理。
  - **文字 scramble**：`scrambleText:{chars:"0123456789"}`（数字步进）；标题行 `yPercent:110→0, duration:1.2, stagger:0.1, ease:"inOutQuart"`。
  - **自绘光标**：`pointermove` → `gsap.to(cursor,{x,y,duration:0.3,ease:"easeOut"})`；hover 时 `scale` 0.4s `inOutQuart` + 文字 scramble 0.5s。
- 可抄：滚动刮擦视频（比自动播放更“被控制”）、Flip 跨容器 + 3D 旋转、光标 300ms 跟随。
- 不可抄：Lottie 数量（本项目 3D 已经重）、scramble 对中文不适用。

### 2.2 The Pendragon Cycle · 实时 3D 世界（Awwwards SOTD，2026-01）

## 4. 对“低空视界”的启示

### 4.1 优先做（P0：纯 CSS/DOM，1–2 天，零新依赖，风险低）

1. **全局颗粒层 + 极细边**（规律 02）：一个 tile、`opacity .025`、`overlay`、fixed；卡片边框改 `rgb(255 255 255 / 10%)` + 顶边内高光。这是投入产出比最高的一项，直接解决“平/简”。
2. **地球环境光层**（规律 01）：`GlobeExperience.module.css .stage` 后加 1 层 900–1100px 椭圆银青光（`screen`，alpha ≤ .05），固定构图光；详情封面区加 1 层。
3. **光标 spotlight**（规律 03）：先做目录卡片（180px、1px 描边光）与详情按钮（120–160px）；`pointermove → rAF → CSS 变量`，`(hover:hover)` 门控。
4. **常驻微动两项**（规律 06）：城市点呼吸 + 星点 twinkle（同屏 ≤12 个，3–5s，`visibilitychange` 暂停）。这两项让画面“活着”，但不动叙事结构。

### 4.2 谨慎做（P1：需要实测帧时间，做了要能回退）

1. **观看器推入**（规律 05/08）：详情页 `pin 70vh` + 封面→画布一次推入（Flip 拟合 + 相机同点），`scrub 0.7`；这是唯一新增的“哇”时刻，先在桌面 Chrome 测帧时间。
2. **首页标题 blur-in**（规律 04）：只给两行标题内层，`blur(8px)→0` 压在前 300ms，总时长不超 1.5s；Safari 单独验证。
3. **气泡/菜单 spring 化**（规律 07）：`stiffness 320–400 / damping 30–34 / mass 1` 或带 1.5–2% 过冲的 `linear()`；替换现有 cubic-bezier，不新增并行体系（Emil 精读的硬规则）。
4. **标题与光层 blend**（规律 09）：`mix-blend-mode: overlay`，alpha .10–.15；先在首页验证可读性（对比度不能掉）。
5. **滚动驱动的相机微动**（规律 05）：首页 0–60vh 内 ±2–3°、±3%；用户一拖就接管。

### 4.3 不做（成本/收益/风险不成立）

- **Bloom / 体积光 / SSR 等后处理**：现有 DPR 上限 1.75、无后处理、移动端要活；用 CSS 光层替代。
- **Lenis 平滑滚动**：会改变现有一切滚动手感、锚点与测试；Arqui9/Immersive 用它是因为整站围绕平滑滚动设计。
- **整页 pin 长叙事 / 多段视频刮擦**：资源与 pin 冲突（拖拽地球、观看器手势）都不可控。
- **全站自定义光标、逐字动画、彩虹渐变、卡片 tilt、SaaS 发光按钮**：见 §3。
- **新增动画库**：现有 GSAP + CSS 足够；弹簧可用 GSAP 或 `linear()` 缓动近似，不引 Framer Motion。

### 4.4 与 v2.0 的关系（升级边界）

- **不改**：时长令牌体系、进出不对称、交互 <300ms、减少动态保留反馈、只动 transform/opacity、单一数值来源、焦点与可用性不依赖动画。
- **改**：新增“材质/光/镜头”层，全部可暂停、可 reduce、可被输入打断；新增动画必须替换旧动画，不叠加。
- **合并方式**：建议在 v2.0 之后追加一节“v2.1 材质与光”，或单独出 `动效设计v2.1.md`；本文只给依据与参数，不直接改 v2.0。

### 4.5 落地验收（在 v2.0 §10 基础上追加）

- 颗粒层/光层在 1440、768、390 下不糊字、不盖住可点击区域（`pointer-events:none`）；
- 光标光晕在拖拽地球、打开气泡时不被遮挡；触屏无残影；
- 常驻动画在切后台 5s 后停止（`visibilitychange`），回前台恢复；
- 观看器推入在 1440 桌面 ≥50fps（Chrome，记录设备），移动端降级为 320ms crossfade；
- 减少动态：颗粒保留（静态材质），光层保留（静态光），微动/推入/blur 全关；
- 所有新增参数写进 `tokens.css` / `motion.ts`，禁止散落字面量（v2.0 §3）。
