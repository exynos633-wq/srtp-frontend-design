# 动效设计 v2.0 · 低空视界

创建：2026-11-03。对应界面：[UI 优化设计](UI优化设计.md)、[UI 优化实施记录](UI优化实施记录.md)。
替换：[动效设计 v1.0](动效设计v1.0.md) 中与新版首页构图、目录排布、详情工具栏冲突的部分；v1.0 的分镜意图、业务边界与减少动态原则继续有效。

状态：**已实施（2026-11-03/04）**，桌面与手机 Chrome 自动化验收通过；真机、Safari 与帧时间未实测，见 §13。数值为制作起点，按实机表现校准；未实测项不写成已通过。

## 1. 这一版要解决的问题

新 UI 已改为“低空视界”展览语言：大字号标题、桌面左文右球、真实彩色地球与云层、展签式目录、详情左看右读。旧动效仍是上一版界面的节奏：

- 首页只有导航和镜头在动，新增的大标题、细则线、目录入口、轨道装饰、页底元信息完全没有入场；
- 目录页头、计数、索引行静态出现，与首排一大一小的展签版式不匹配；
- 详情信息列只在封面转场后整组淡入，工具栏、更多菜单、设置/信息面板仍是硬切；
- 气泡开关、地图惯性、减少动态策略与 v1.0 遗留实现不一致（`ease-in` 关闭、最后一帧位移充当惯性、reduced-motion 时长归零）。

本版目标：**让新界面的叙事层（首页开场、目录、详情）有统一的展览节奏；让交互层保持短、准、可打断**。不增加装饰性循环动画，不引入新依赖。

## 2. 动效原则

1. **叙事只发生一次**：首页开场、目录首次进入、详情首屏各一段，返回时恢复状态不重播。
2. **交互永远快于叙事**：按钮、hover、菜单、面板 100–280ms；叙事段 1.2–1.6s 且任何输入立即接管。
3. **只动 transform / opacity**（SVG 线用 `stroke-dashoffset`）。不动 width/height/top/left，不用 `ease-in`，不用 `scale(0)`。
4. **进出不对称**：退出比进入快，且走同一路径；关闭从当前状态接管，不排队播完。
5. **可读性不依赖动画**：标题、正文、导航、开始预览按钮在动画完成前就可用；封面交接只由真实首帧触发。
6. **减少动态保留反馈**：去掉位移、镜头、惯性、云层漂移，但保留 120–160ms 的颜色/透明度状态变化，不把时长全部归零。
7. **单一数值来源**：CSS 变量与 `frontend/src/lib/motion.ts` 同源；GSAP 时间轴不再出现散落的 `0.18`、`0.42`、`power2.out` 字面量。

## 3. 令牌

### 3.1 时长与缓动（`frontend/src/styles/tokens.css`）

| token | 值 | 用途 |
| --- | --- | --- |
| `--dur-press` | 140ms | 按压缩放、开关状态 |
| `--dur-fast` | 160ms | 颜色、边框、焦点、菜单关闭 |
| `--dur-base` | 220ms | hover、气泡、工具栏、面板 |
| `--dur-slow` | 280ms | 面板进入、信息列单项 |
| `--dur-enter` | 380ms | 首屏信息段、详情列入场 |
| `--dur-scene` | 600ms | 卡片揭示、封面交接、放大恢复 |
| `--dur-cinema` | 1200ms | 首页镜头推进（仅叙事段） |
| `--ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | 进入、退出、默认 |
| `--ease-in-out` | `cubic-bezier(0.77, 0, 0.175, 1)` | 屏上移动、镜头、放大恢复 |
| `--ease-drawer` | `cubic-bezier(0.32, 0.72, 0, 1)` | 抽屉式面板、菜单 |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 颜色/边框等短反馈 |
| `linear` | — | 进度、骨架 shimmer、录制计时 |

GSAP 映射（`motion.ts`）：`out → power2.out`，`inOut → power2.inOut`，`enter → power3.out`，`drawer → power3.out`，`cinema → power2.inOut`。

### 3.2 时间常量

公开分钟数统一在 `motion.ts` 的 `DUR`（毫秒）与 `SEC`（秒）导出；GSAP 只能使用 `SEC.*` 或 `DUR.* / 1000`，CSS 只能使用 `var(--dur-*)`。

## 4. 首页开场（S1）

触发：`HomePage` 挂载且非减少动态、非本次会话已看过。地球场景懒加载就绪后接入同一节奏；任何 pointerdown / 滚轮 / 键盘立即 `takeOver()` 结束剩余镜头。

桌面时间轴（相对时间，总约 1.35s）：

| 时间 | 元素 | 动作 | 时长 / 曲线 |
| --- | --- | --- | --- |
| 0ms | 公开导航 | `autoAlpha 0→1`、`y -8→0` | 320ms out |
| 80ms | 标题上细线 | `scaleX 0→1`，origin left | 420ms out |
| 140ms | `A NEW PERSPECTIVE` | `opacity 0→1`、`y 8→0` | 300ms out |
| 220ms | 标题第 1 行“低空之上” | 内层 `yPercent 110→0`（外层 overflow hidden） | 560ms enter |
| 340ms | 标题第 2 行“另见世界” | 同上，错峰 120ms | 560ms enter |
| 560ms | 副标题 | `opacity 0→1`、`y 10→0` | 380ms out |
| 660ms | 目录入口按钮 | `opacity 0→1`、`y 8→0` | 320ms out |
| 100ms | 地球镜头 | `introDistance 1.10→1`，经度 `OPENING_VIEW→INITIAL_VIEW` | 1200ms cinema |
| 260ms | 星点/轨道/地形装饰 | 装饰层 `opacity 0→1`、`scale .98→1`；地形线 `stroke-dashoffset 1→0` 错峰 60ms | 900ms / 900ms |
| 800ms | 城市点位 | `opacity 0→1`，stagger 70ms，仅正面点 | 320ms out |
| 1000ms | 操作提示 | `opacity 0→1` | 300ms out |
| 1100ms | 页底元信息 | `opacity 0→1` | 300ms out |

手机（<768）：文案在文档流上方，场景在下。按同一顺序播放；除标题外位移减半；不播放轨道/地形绘制；场景懒加载完成后开场自带 120ms 淡入即可，不延迟文案。

减少动态：所有元素直接最终状态；导航与按钮保留 160ms 颜色/透明度变化；不播放镜头推进、不做标题位移；点位直接可见。

再次回到首页：不重播开场，恢复上次视角（现有行为），仅 160–220ms 的导航/场景稳定过渡。

## 5. 地球交互（S2）

| 场景 | 规格 |
| --- | --- |
| 拖拽旋转 | `pointerdown` 即响应；1:1 跟手；5px 方向迟滞；`setPointerCapture`；拖动中不写 React state |
| 松手惯性 | 记录最近 3–5 个 `pointermove` 的 `(t, x, y)`；`v = Δ/Δt`（px/s）；按 `project = (v/1000)·0.998/(1−0.998)` 求投影像素，换算约 `1px = 0.2°`，并**限幅到 90°（450px）**，避免一次甩动转过半球；`duration = clamp(200 + 投射像素·0.5, 200, 600)ms`；`power3.out`；慢拖停住松手不产生惯性；减少动态不产生惯性 |
| 键盘 | 方向键/`+`/`-` 直接改值，无补间（沿用 v1.0 结论） |
| 聚焦城市 | 最短经度路径，550–750ms，`power2.inOut`；可被再次拖动/滚轮立即打断 |
| 点位 hover | dot `scale 1.22`、光晕 180ms；选中/展开 `1.35`；仅 `(hover:hover) and (pointer:fine)` |
| 气泡打开 | `opacity 0→1`、`scale .96→1`、`y 6→0`，220ms out；`transform-origin` 指向点位方向（左/右/上） |
| 气泡关闭 | 160ms out，`opacity→0`、`scale .98`；从当前值起动画，不排队 |
| 连接线 | 选中后 `stroke-dashoffset` 240ms 画出；关闭同步回收 160ms |
| 气泡内列表 | 行 `opacity 0→1`、`y 4→0`，stagger 40ms，首屏最多 4 行 |

`回退来源`：键盘 Tab 聚集到背面点先转镜头，再展开气泡；转镜头期间焦点保持，不播放气泡动画直到镜头完成。

## 6. 目录（S3）

**页头入场**（首次进入，约 700ms）

| 时间 | 元素 | 动作 | 时长 |
| --- | --- | --- | --- |
| 0ms | `SPATIAL COLLECTION / 空间档案` | opacity + y 6 | 280ms |
| 80ms | “全部作品” | 外层 overflow hidden，内层 `yPercent 110→0` | 520ms enter |
| 180ms | 描述文字 | opacity + y 8 | 320ms |
| 240ms | 计数 `10` / `件公开作品` | opacity + y 6，数字与标签错峰 40ms | 300ms |
| 320ms | 索引行 | `scaleX` 细线 0→1 + 文字 opacity | 360ms |
| 360ms 起 | 首排卡片 | 行揭示，每行 50ms，单项 420ms、`y 12→0` | 420ms out |

**滚动揭示**：沿用行级 IntersectionObserver（threshold .12、底部 -8%），单行 420ms、y 12、stagger 50ms；不排队等待封面；减少动态直接显示。

**卡片交互**

- hover：边框色 180ms；封面 `scale(1.02)` 220ms out；箭头圆底填充 160ms；标题不位移；
- press：`scale(0.985)` 140ms（仅 transform），释放回 1；
- 焦点：`outline 2px var(--color-focus)` 立即出现，不加动画；
- 返回目录：恢复滚动位置与入口焦点，不做反向封面转场（保持可预期，v1.0 “恢复状态不重播”）。

**骨架/状态**：shimmer 1.4s linear；状态消息 180ms opacity；错误/空态面板 y 8、250ms out。

## 7. 详情（S4）

**封面连续转场**：保留 v1.0 机制（克隆图 + 遮罩 + `Flip.fit`），只改节奏：

- 克隆层 `Flip.fit` 620ms `power3.inOut`；遮罩 180ms `--ease-out`；
- 信息列在封面到位前 200ms 开始，逐项 `opacity + y 10`、单项 380ms、stagger 60ms；
- 直接进入详情（无有效来源）：封面 `opacity + y 12`、380ms；信息列同上；
- 减少动态：无克隆层，直接显示目标状态，焦点立即落在标题。

**开始预览**：按钮 `scale(.97)` 140ms；封面到观看器由真实首帧触发，交接 320ms crossfade；观看器外壳 `opacity + y 8` 260ms；工具栏 200ms 后淡入。

**观看器工具栏与菜单**

- 工具切换：下划线 `scaleX` 180ms、颜色 120ms；模式按钮仅颜色/背景变化；
- 更多菜单：打开 `opacity 140ms + y 6 + scale .98`，origin 右上；关闭 100ms；从当前状态接管，连点即反向；
- 显示设置/模型信息面板：进入 220ms `--ease-drawer`，`y 8→0`；关闭 160ms；面板互斥时不叠加两张动画；
- 放大查看/恢复：420ms `power3.inOut`（位置与尺寸用 Flip 同款拟合），结束清理临时内联样式；减少动态直接切换；
- 全屏：使用浏览器原生过渡，不额外动画，仅按钮状态 160ms。

## 8. 反馈与状态（S5）

| 场景 | 规格 |
| --- | --- |
| 主按钮/次按钮按压 | `scale(.97)` 140ms，释放 180ms out |
| 链接/导航 hover | 颜色 120–160ms `--ease-standard`；下划线 origin center `scaleX` 180ms |
| 焦点轮廓 | 立即出现，不做淡入 |
| 加载/骨架 | shimmer linear；point 脉冲仅“确实在等待”时运行，页面就绪后停 |
| 状态/错误/空态 | 180–250ms opacity，最多 y 8，不弹跳 |
| Mock 标识/元信息 | 不参与动画，避免每帧或长循环 |

## 9. 性能与可访问性

- 只对 `transform`/`opacity` 做过渡；现有 `transition: width` 全部改为 `scaleX` 或直接设值（上传进度、查看器进度）。
- `will-change` 只在实测掉帧的动画元素上短暂使用，不铺到列表或大容器。
- 不逐帧 `setState`；GSAP 只写 ref / Three 对象；`useGSAP` 负责卸载清理；路由切换、resize、打断都恢复到最终可见状态。
- 地球保持现有限制：DPR 上限 1.75、无全屏后处理、纹理分级；动画不改变渲染分辨率。
- `prefers-reduced-motion: reduce`：`--dur-enter/--dur-scene` 归零，`--dur-fast/base` 保留 160/220ms；JS 侧取消镜头、惯性、标题位移、云层漂移与卡片位移动画，保留状态与焦点。
- 所有 hover 动效门控 `(hover: hover) and (pointer: fine)`；触屏用 `:active` 反馈。
- 动画永远不是可用性前置条件：开始预览、导航、返回、错误恢复都不等待时间轴。

- 覆盖：首页开场构成、目录页头、详情信息列与工具栏的节奏；v1.0 的 1.2–1.6s 总长、气泡 280–380ms、卡片 450–650ms 的区间仍成立，本版取区间内更快的一侧。
