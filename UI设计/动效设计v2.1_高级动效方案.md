# 动效设计 v2.1 · 低空视界「光域测绘」高级动效方案

创建：2026-11-04。状态：**P0「布光」已实施（2026-11-04）**；P1/P2 仍为方案。实施记录见 §8。
依据：[动效设计 v2.0](动效设计v2.0.md)（已实施）、[Aceternity 全量调研](动效调研_Aceternity.md)、[高级动效参考调研](动效调研_高级动效参考.md)、[UI 优化设计](UI优化设计.md)、[视觉规范 v1.0（深色）](视觉规范v1.0（深色）.md)。

本文回答一个问题：**在 v2.0 已经“顺滑、正确”的基础上，怎样把“简洁”变成“有光、有层次、有高级感”**。数值为建议值，实施时按实机校准；未实施前不写成已达成。

## 1. 为什么现在显得“简洁”

v2.0 解决了节奏与正确性，但画面语言仍然只有一种：**位移 + 透明度**。

| 维度 | 现状（v2.0 代码/画面） | 高级感的来源 | 差距 |
| --- | --- | --- | --- |
| 光 | 没有光源。深色底是纯 `#080D12` 平涂 + 静态轨道线 | 有方向的布光、体积光、边缘光、呼吸辉光 | **最大缺口**：画面“不发光” |
| 层次 | 文字、地球、卡片、导航都在同一平面；最远与最近没有区别 | 视差、景深、透视、前景颗粒/暗角 | 目录与详情仍是“平面网页” |
| 材质 | 卡片是 1px 描边矩形；按钮是纯色块 | 指针光斑、边框光晕、反光、玻璃、颗粒 | 没有“被照亮”的材质反应 |
| 节奏 | 所有入场 300–600ms、同一组 ease-out、同幅度 8–12px 上移 | 慢环境 + 快交互的对比；一屏一个高光时刻 | 全程平均，没有重点 |
| 交互 | hover 只改边框色 / 轻微缩放 | 磁吸、光带、指针跟随、聚焦关系 | 手感“普通网页” |
| 常态 | 开场结束后完全静止（只有云层缓慢漂移） | 低频环境动效让画面“活着” | 没有 ambient 层 |

结论：不是缺动画，而是**缺光、缺纵深、缺材质、缺一个签名瞬间**。因此 v2.1 不再增加“更多位移”，而是增加“光与空间”。

### 2.3 反面清单（会立刻变廉价）

彩虹渐变/多色光晕、流星/粒子雨、每个元素都入场、`blur(20px)` 全屏、所有卡片 3D 倾斜、持续跑马灯、光标特效盖过内容、hover 时元素大幅位移（>10px）、低频设备上的大面积模糊、暗色上低对比小字。

## 3. 动效语言 v2.1：「光域测绘」

三个母题，全部来自本项目的既有视觉：

- **光（Light）**：展厅洗墙灯、顶部光锥、地平线辉光 —— 解决“画面不发光”。
- **测绘（Survey）**：网格、刻度、扫描线、雷达波、轨迹光束 —— 契合轨道/地形/城市点位。
- **空间（Depth）**：视差、透视、遮罩揭示、景深与颗粒 —— 把平面变成展厅。

### 3.1 四层强度预算

| 层 | 周期/时长 | 幅度上限 | 例子 |
| --- | --- | --- | --- |
| 环境层 ambient | 8–20s 循环 | 位移 ≤40px、alpha ≤0.12 | 光带摆动、大气呼吸、网格漂移、颗粒 |
| 叙事层 narrative | 0.8–2s 一次 | 位移 ≤24px、scale ≥.96 | 标题揭示、观看框上台、扫描线 |
| 交互层 interaction | 120–320ms | 位移 ≤8px、scale .97–1.02 | hover、按压、菜单、面板 |
| 反馈层 feedback | ≤160ms | 颜色/透明度 | 按钮、焦点、状态 |

### 3.2 三条硬规则

1. **一屏一个高光**：首页=光带+标题光扫；目录=卡片光斑/扫描线；详情=观看框上台。其余效果不得抢戏。
2. **光只出现在负空间**：地球实体、卡片封面、图片上不加发光；光在标题背后、边框上、连接线上。
3. **所有循环可暂停**：离屏（IntersectionObserver）、页面隐藏（`visibilitychange`）立即暂停；`prefers-reduced-motion` 下全部静态。

### 3.3 新增令牌（扩展 `tokens.css` / `motion.ts`）

```css
--ambient-slow: 12s;      /* 光带/呼吸 */
--ambient-slower: 20s;    /* 网格/星点漂移 */
--light-wash: rgb(84 200 193 / 7%);
--light-beam: rgb(198 226 230 / 5%);
--grain-opacity: 0.035;
--spotlight-size: 320px;
--glow-border-size: 1px;
```

## 4. 页面级方案

### 4.1 首页「布光的展厅」

| 元素 | 动效 | 参数 | 实现 |
| --- | --- | --- | --- |
| 固定构图光 | 地球后方一层大椭圆冷光，让深色底“有来源” | 900–1100px；`rgb(198 226 230 / 5%)` → `rgb(84 200 193 / 4%)` → 透明；`mix-blend-mode: screen`；静态不动 | CSS 径向渐变层（不加 blur） |
| 左右洗墙光带 | 两条 45° 淡青光带缓慢横移 | 560×1380 / 240×1380；`x ±40px`；9–12s ease-in-out yoyo；opacity .5；青绿 `hsla(177,46%,55%,.07)` | 2 个绝对定位层 + CSS animation（GPU transform），`will-change` 仅桌面 |
| 顶部光锥 | 椭圆光斑从左上落下定位 | 入场 900ms ease-out；`blur` 100（移动端 70）；`fill-opacity` .12；落点在地球与标题之间负空间 | SVG + `feGaussianBlur`，一次性 |
| 点阵底纹 | 40px 网格极缓慢漂移 | opacity .035；位移 0→20px / 30s linear yoyo | CSS background-position（低帧率友好） |
| 颗粒噪点 | 全屏静态噪声 | 3%；256px tile；`mix-blend-mode: overlay`；`pointer-events:none`；**不盖 canvas** | SVG `feTurbulence` data URI |
| 标题光 | 入场时一次冷白光扫；之后靠“字与底的光互动”而不是循环 shimmer | 首屏入场后 1.2s 触发一次，1.1s，透明度 0→.35→0；叠加 10–15% 银青 `mix-blend-mode: overlay` 层，随环境光极慢移动 ±5% / 8–12s | `background-clip:text` 一次性 + blend 层 |
| 标题逐行 | 保留 v2.0 揭示，加 blur 8→0 | 560ms，两行错峰 120ms；blur 只压前 300ms | GSAP（v2.0 已有） |
| 副标题 | 逐短语 blur(8px)→0 | 短语 stagger 60–80ms，总 ≤700ms | GSAP（中文按短语数组） |
| 主 CTA | 绕边光点 + 磁吸 + hover 光扫 | 6s/圈；光斑 48px；磁吸 strength .3、位移 ≤5px、spring 320/32（过冲 ≤3%） | SVG + rAF；指针门控 |
| 地球大气 | 辉光呼吸 | opacity .45→.7，8s ease-in-out yoyo | CSS 径向渐变层（非全屏 blur） |
| 点位 | 雷达波纹（仅 hover/选中） | 2 圈，1.6s/圈，accent 18%→0；选中时再 1 次 | CSS `::after` scale + opacity |
| 连接线 | 选中城市时一束光点沿线跑到气泡 | 1.2s 一次；之后保持 1px 线 | `pathLength=1` + dashoffset（v2.0 已有，加光点） |
| 轨道刻度 | 60s 转 0.5° | 极慢，几乎不可察 | CSS animation（reduced 下停） |
| 光标 spotlight | 桌面 400px 冷光斑跟随 | alpha .04–.06；`mix-blend-mode: lighten`；`lerp 0.1`；离开窗口淡出 200ms | CSS 变量 `--mx/--my` + transform |
| 手机 | 光带保留、光锥减弱、关闭光标/网格漂移 | 大气呼吸保留；位移减半 | 媒体查询 + JS 分支 |

开场顺序（保留 v2.0 1.35s 骨架，插入光层）：0–260ms 光带淡入 → 260ms 光锥落位（900ms）→ 260ms 标题逐行 → 560ms 副标题逐短语 → 660ms CTA 光带起跑 → 1000ms 环境层全部就位（进入 ambient 循环）。

### 4.2 目录「沿着档案走」

- **页头**：lamp 灯管（1px 亮线 0→100% 展开 600ms，1 层 blur 光团 900ms）+ 标题逐行揭示 + 光扫（同首页，只播一次）+ 计数 ticker（`00 → 10`，800ms，`tabular-nums`）。灯管不循环。
- **签名扫描线**：首次进入目录，一条 1px 的 accent 渐变线从左到右扫过首屏内容（800ms，`mask-image` 移动），像测绘仪扫过展签；只播一次，reduced 下不播。
- **卡片**：
  - 边框：`glowing-effect` 1px conic（accent→银灰→透明），proximity 120px 激活，光段 2.5s 绕边；不 blur 内层；
  - 首排大卡：`card-spotlight` 320px 光斑（accent 10%）+ 封面视差（滚动 ±6px）；**不做 3D tilt**（调研 B 明确建议：展览语言里倾斜容易廉价，优先用光与遮罩）；
  - 封面揭示：`clip-path inset(0 0 100% 0)` → 0，700ms ease-out（行揭示时每张错峰 60ms，仅首屏）；
  - hover 聚焦：同排其他卡片 opacity .55（仅桌面 `(hover:hover)`），形成“导览”关系；
  - 移动端：无光斑，保留封面揭示与边框色。
- **索引行**：垂直 tracing beam 随滚动推进（scroll-driven，`ScrollTrigger` 或 rAF 读取 scrollY），光点 1200ms 缓入；只在目录页存在。

### 4.3 详情「展品上台」

- **观看框**：进入时 `perspective:1000px`，外壳 `rotateX 12°→0`、`scale .96→1`、`y 24→0`，700ms ease-out；底部加一层柔和长阴影（`box-shadow: 0 40px 80px -40px`）随 transform 收敛。滚动到详情顶部时随滚动联动（前 240px 内 `rotateX` 12→0），实现 `container-scroll` 的上台感。
- **封面**：遮罩揭幕（`clip-path` 从下往上 600ms）+ 桌面 hover `lens`（2 倍放大圆形镜，mask 跟随指针，仅 1440+）；已有封面 Flip 转场保留。
- **信息列**：逐项 mask 揭示（`translateY(100%)→0` + `blur 6→0`，单项 420ms，stagger 70ms）；城市/编号 mono 字符 stagger 20ms；点赞预留做 3s 呼吸光（opacity .55→.8）。
- **工具栏**：active 下划线用光带（scaleX + 光斑经过一次）；悬停时工具按钮被 320px 指针光斑轻微照亮；更多菜单 spring 弹出（220/28）+ 背后 `backdrop-filter: blur(0→8px)` 渐入 180ms；设置/信息面板进入 220ms + 内容 stagger 40ms。
- **开始预览**：封面被扫描线扫过（600ms）→ 真实首帧到达后 320ms 交接（v2.0 保留）；失败/降级路径不播装饰、直接显示状态。
- **移动端**：去掉 lens、tilt、长阴影，保留遮罩揭示与信息列 stagger。

### 4.4 全局

- **路由转场**：页面离场 240ms（内容 opacity→0 + 4px 上移），进场 400ms（内容 + 光幕：一条 1px 亮线从顶部展开为柔光 160ms 后淡出）。用 GSAP 覆盖层实现；可用 View Transitions API 时优先，失败回退。
- **加载态**：所有“加载中”改为“扫描 loader”：网格底 + 1px 扫描线 1.6s 往复；点击态/骨架 shimmer 保留。
- **按钮与链接统一**：主按钮 hover 光扫 600ms（`background-position` 位移）+ 按压 0.97；文字链接下划线从 0 展开 180ms，颜色过渡 120ms；焦点环加一次 300ms 光晕（仅键盘）。
- **噪点与暗角**：全局噪点 3.5% + 现有 vignette，让深色底有“胶片/展墙”质感，而非纯色平面。

### 4.5 减少动态（必须逐项交付）

| 效果 | reduced 降级 |
| --- | --- |
| 环境光带/网格/刻度/大气呼吸 | 全部静态（保留最终光位） |
| 标题光扫/扫描线/连接线光点 | 不播放 |
| 卡片光斑/倾斜/视差 | 只保留边框颜色 160ms |
| 磁吸/自定义光标 | 关闭 |
| 观看框透视/封面遮罩 | 直接显示，保留 160ms 透明度 |
| 扫描 loader | 静态骨架 |

## 5. 技术方案

### 5.1 依赖决策

**不引入 framer-motion / Tailwind / tsparticles / 新的 3D 库。** Aceternity 的效果全部用现有栈等价实现：

| Aceternity 概念 | 本站等价实现 |
| --- | --- |
| `useMotionValue` + `useMotionTemplate`（指针光斑） | `rAF` 节流写 CSS 变量 `--mx/--my`，`mask-image` 读取；事件委托到网格容器 |
| `AnimatePresence`（菜单/面板进出） | 已有 `data-closing` + CSS transition / GSAP timeline |
| `whileInView` / `initial/animate` | IntersectionObserver（一次性）+ GSAP |
| scroll 驱动（container-scroll、tracing-beam、parallax） | `ScrollTrigger`（gsap 包内免费插件，需注册）或 rAF 读 `scrollY` |
| spring（磁吸、菜单） | GSAP `elastic` / 自定义 spring（`quickTo` 循环），仅用于可抓取元素 |
| SVG 描边光点（moving-border、tracing-beam） | `getTotalLength`/`getPointAtLength` + rAF + `pathLength=1` |
| 大面积渐变光层 | CSS `radial-gradient` + `transform` 动画，**不用** `feGaussianBlur` 大半径（移动端） |

### 5.2 代码结构（新增，均为可复用小组件）

```
src/components/fx/
  AmbientLights.tsx     首页洗墙光带 + 顶部光锥 + 点阵底纹
  GrainOverlay.tsx      全局噪点（SVG data URI，静态）
  GlowBorder.tsx        1px 指针 proximity 光边框（目录/详情卡片）
  Spotlight.tsx         指针光斑容器（事件委托，CSS 变量）
  ScanLine.tsx          扫描线（目录签名 / 观看器开始预览）
  Magnetic.tsx          磁吸包装（strength/maxDistance 参数化）
  TiltCard.tsx          ±2.5° 3D 倾斜（spring，桌面 only）
  TracingBeam.tsx       索引光束（scroll 驱动）
src/lib/lightField.ts   指针→CSS 变量、rAF 调度、离屏暂停
src/lib/motion.ts       扩展 AMBIENT 时长、LIGHT 透明度常量
```

### 5.3 性能预算

- 每屏同时动画元素 ≤12；粒子 ≤200；`blur ≤ 6px` 且只在不动的层；全屏渐变只用 1–2 层。
- 光层：alpha .02–.08、`mix-blend-mode: lighten/screen`、每帧只写 `transform`；指针效果用 `lerp 0.1` 平滑，**不**逐帧改 `background-position`；1px 边框光用 180–200px radial mask。
- 环境层用 CSS animation（合成器线程）；指针效果用 rAF 单调度器，1 帧最多更新 1 次。
- 离屏/页面隐藏暂停；`will-change` 只挂动画元素、结束即摘除。
- 不改变 DPR 上限 1.75；Three 场景不因本方案增加后处理。
- 目标：1440 桌面 60fps；中端手机 30fps+；构建增量 ≤15KB（不含已有 Three）。

### 5.4 验收

1. 截图/录屏前后对比：首页、目录、详情各 1 段（正常 + reduced）。
2. `motion-v2.spec` 不回归；新增 E2E：光层存在且不拦截指针、reduced 下循环层静止、无 console error。
3. 性能：Chrome Performance 录制 1440/390 各 5s，无 >50ms 长任务（Three 初始化除外）。
4. 人工：每屏一个高光、无抢戏、无低对比文字、焦点环可见、触屏可完成全部操作。

## 7. 风险与取舍

- **过度装饰**：环境层总 alpha 必须 ≤0.12，任何效果让人“先看到动画而不是内容”就删。每屏只留一个高光。
- **性能**：移动端关闭光斑/倾斜/光标，光带降为静态渐变；全部循环可暂停。
- **与 v2.0 的关系**：v2.0 的时长/缓动/交互节奏继续有效；本方案只新增“光、材质、纵深”，不改已结算的叙事时长（1.2–1.6s）。
- **版权**：只借鉴 Aceternity 的公开思路与参数，自行实现；不复制其素材与代码文件，不引入其依赖。
