# 公开端视觉升级 v2

实施日期：2026-10-22。依据：[Aceternity UI 调研与视觉升级建议](Aceternity%20UI调研与视觉升级建议.md)及用户“按照你的建议执行”的确认。

本轮公开端采用“建筑数字展馆”方向。涉及字号、构图、材质、光效、目录布局的规则，以本轮实现为准，替代 v1.0 中对应的审美限制；业务状态、数据真实性和输入等价原则继续保留。

## 已实现

- 首页：可见的中文展陈标题、语义分行揭示、冷暖聚光、暖金主入口与磁吸内容反馈；地球偏右，手机上下重排。调整了地球光向、环境光与大气边缘强度。
- 导航：桌面玻璃表面与滚动收拢；手机保留品牌和三个文字入口。这里使用渐变、边缘反光与磨砂玻璃，没有引入仅 Chromium 支持的液态折射。
- 目录：保留真实排序的主次网格、作品编号、卡片景深倾斜、指针边缘光与表面反光。整卡仍只有一个链接。
- 详情：大字号作品名、大画幅观看区、封面下方的预览操作区、分栏展册式介绍；保留真实查看器、放大／恢复与结束逻辑。
- 连续性：GSAP 入场与卡片倾斜分层；点击时归正后读取封面来源，继续使用既有封面连续转场。
- 手机：城市气泡打开时标题区退场，防止相互遮挡；短屏可纵向滚动，气泡按可见视口保留内部滚动。
- 减少动态：标题揭示、装饰开场、磁吸与卡片倾斜提供静态呈现。
- 素材：从现有院落、长城 GLB 的真实客户端渲染画面导出两张封面，仅用于对应的 Mock 种子作品。

## 技术取舍

借鉴 Aceternity 的 Spotlight、Comet／3D Card、Glowing Effect、Magnetic Button 与 Resizable Navbar 的表现方式，使用本项目已有 React、CSS Modules 与 GSAP 实现适配，没有直接引入整套 Tailwind／Motion 或迁移 Next.js。

没有新加后台、评论、点赞、筛选、统计等业务能力。展示序号表示目录顺序，不代表排名或精选。

标题使用系统宋体字体链；没有声称已打包正式字体。其余占位作品、演示地球纹理和 Mock 标识继续明确呈现。真实素材不足的作品没有套用其他作品的封面。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过；保留原有查看器大分包提示，本轮没有改动其打包方式。
- `npm test`：24 个测试文件、235 个用例通过。
- Chrome 浏览器用例分两组完成，共 55 个通过（城市气泡／目录／新增展陈适配 31 个；首页／路由／完整演示流程 24 个）。
- 覆盖 320、390、768、1440 宽的公开页、预览入口、横向溢出、指针倾斜后的点击、减少动态、城市气泡、共享封面转场、预览启停与放大恢复。
- 本轮实页截图脚本未捕获页面 JavaScript 异常；`git diff --check` 通过。

浏览器检查使用本机 Chrome 与模拟视口，不代表 Safari／Firefox、手机真机或性能帧率验收。
