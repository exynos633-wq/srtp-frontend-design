## 1. 设计概念

**夜间建筑档案馆：展馆熄灯以后，建筑以数字模型和图纸的方式被重新观看。**

- **墨**是空间：页面没有明亮的展厅灯，只有接近黑的墨面、极细的分隔线和低对比的层次。三维地球与建筑模型是唯一有真实材质和光亮的部分。
- **纸**是信息：标题、展签、说明文字像贴在墨色墙面上的纸签，纸白为字、留白为界。纸感来自排版和空间，不靠拟物纹理。
- **朱砂**是引导：像档案上的批注、藏印和展签编号，只在需要被看见的地方出现——编号、1 px 当前项短线、选中点位、极小的印记。它不铺满、不发光、不替代正文。

“图纸与展签”是观看方式的比喻，不是把页面做成工程蓝图：

- 用编号、细分隔线、轴网式对齐和短标注建立档案秩序；
- 每件作品按“编号 → 名称 → 城市 → 说明 → 观看”的顺序阅读，像读一张展签；
- 不伪造尺寸、比例、材料、年代等未经核实的技术信息，也不把装饰线伪装成图纸数据。

关键词：夜间、安静、克制、档案感、东方而不古风。明确避免：暖金、冷青、霓虹、彩色辉光、玻璃拟态、大红大金的“国风”符号、云纹灯笼等装饰、大面积朱砂。

补充规则：

- 20 px 以下文字一律按普通文字 4.5:1 检查，不依赖大字豁免。

### 2.4 使用纪律

1. **纸白是唯一主按钮色。** 主按钮用 `paper` 底＋`ink-950` 字，hover 用 `paper-dim`，按下不换成朱砂。一屏只突出一个主按钮；次按钮用实色底、`paper` 文字和 `line-strong` 边界。
2. **朱砂不超过首屏可见面积的 5%。** 只以“引”的形式出现：编号、1 px 当前项短线、选中点、短边框、极小印记。按整块可见面积估算，不按动画帧累计；超过 5% 视为偏离方向。朱砂不做大按钮、大色块、长段文字、渐变背景或发光。
3. **无金色、无青色。** v2 的暖金、冷青、冷银全部退出公开端。真实状态的成功色 `#9CB8A6` 只用于成功反馈，不能当第二强调色或装饰色。
4. **光只用中性白。** 聚光、边缘光、指针光、辉光与反光只用 `paper` 白（低不透明度）或纯黑阴影。朱砂和状态色不发光；点位反馈用放大、实心点和纸白短环表达，不增加红色光晕。
5. **朱砂文字与朱砂图形分开。** 小号朱砂文字用 `accent-text`（5.54）；`accent-line`（4.15）只承担图形、大字和 1 px 线，避免在深底上写小字。
6. **状态色只表达真实状态。** 错误、警示、成功必须同时有文字或图标；没有真实事件时不得预置颜色，也不得用状态色做装饰。
7. **建筑图像保持真实材质。** 不加金色、青色或朱砂整体滤镜，不用彩色罩层统一风格；真实模型渲染的浅石、木构和绿植颜色应当被保留。

## 3. 字体与排印

### 3.1 字体

| 用途 | 字体栈 | 说明 |
| --- | --- | --- |
| 展示标题、作品名、区块标题 | `"Source Han Serif SC", "Noto Serif SC", "Songti SC", "STSong", "SimSun", serif` | 中文衬线。正式字体尚未打包，先用系统宋体字链；取得正式字体后只替换字体文件，不改层级 |
| 正文、导航、按钮、表单、标签 | `"Source Han Sans SC", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif` | 中文无衬线 |
| 英文、数字、编号 | `Inter, system-ui, "Segoe UI", sans-serif` | 编号使用等宽数字（`font-variant-numeric: tabular-nums`），保证列表对齐 |
| 模型格式等短元信息 | `"IBM Plex Mono", ui-monospace, SFMono-Regular, Consolas, monospace` | 只用于 gLTF、3DGS 等短标签；不用于正文和长说明 |

字体未入库前只声明回退栈，不得在页面或文档中声称已安装正式字体。

| 正文／建筑介绍 | 16px／28px | 16px／26px | 黑体 400 |
| 次级文字（城市、说明） | 14px／22px | 14px／22px | 黑体 400 |

| 辅助元信息 | 12px／18px | 12px／18px | Inter／黑体 400 |

排印纪律：

- 正文每行约 24–32 个汉字；长介绍在这个宽度内换行，不压成窄栏。
- 标题按语义分行，不逐字拆开，不用伪加粗、超细中文、全大写中文、超宽字距或液晶字体。
- 标题和正文的字距不要为了“设计感”拉宽；英文小标签可以加字距，中文标题保持自然。
- 200% 文字放大时允许组件增高和折行，不以固定高度裁字。
- 正文中只允许短词、编号或链接使用朱砂色，不把整段介绍染成 `accent-line` 或 `accent-text`。

### 4.2 圆角、边线与阴影

| 项目 | 值 |
| --- | --- |
| 浮层／气泡 | 8px |
| 实色面板 | 2–4px |
| 卡片、图像框 | 0–4px，优先直角 |
| 输入、按钮、标签 | 2px |
| 点位、状态圆点 | 50%（仅圆形语义） |

- 不使用胶囊形按钮、胶囊形导航或大面积圆角卡片。
- 卡片常态只靠 1 px `line` 和留白分界；hover／focus 时边框改为 `line-strong`，可加中性黑阴影。
- 焦点线 2 px `focus`（纸白），与控件之间留 2 px `ink-950` 间隔；在纸白按钮上，间隔用 `ink-950`，焦点线仍为纸白并向外可见。

### 4.3 材质

- **实色墨面，不用玻璃。** 导航、气泡、卡片、信息列、浮层全部是实色 `ink` 系列；不使用 `backdrop-filter`、毛玻璃、彩色玻璃或透明面板。手机导航与所有工作界面必须为实色。
- **纸感来自排版，不来自贴图。** 依靠纸白文字、编号、细线、留白和适度的墨面纵向渐变建立“纸与档案”的感觉；不新增纸张噪点大图、纹理照片或拟物纸边。若实现极轻的纸纹，只能是静态 CSS 且不透明度不超过 2%，不得影响文字对比度与滚动性能。
- **图像有固定承托。** 封面和观看区落在 `#0E0F10` 的固定不透明底上，比例为 16:10，不加厚相框、不加彩色描边。图像四角只做 4px 以内的轻微收边。
- **光只作中性白。** 页面顶部可有一层极弱的纸白渐亮或径向光，范围不超过首屏的 60%，不遮挡操作；不得出现金色、青色或朱砂色的环境光、边缘光、辉光。
- **阴影只用中性黑。** 卡片常态无阴影；浮层和 hover 才允许向下投影。禁止彩色阴影、彩色外发光和发光描边。

## 5. 首页与公开导航

### 5.1 公开导航

- 导航为实色 `ink-950` 底、1 px `line` 下边线，不使用玻璃、模糊和胶囊边框。
- 左侧保留文字站名“建筑模型展厅”，衬线字标；可保留一行小号英文说明，字距略宽但不抢标题。
- 右侧保留现有三个入口：地图探索、全部作品、后台管理。**不新增“关于”页面，不新增搜索入口。** 当前项用 `paper` 文字和 1 px `accent-line` 短线，其他项用 `stone`。
- 桌面悬停与键盘聚焦共用同一条 1 px 朱砂指示线，指示线在当前项与指针／焦点项之间移动；减少动态时直接落在目标项，不播移动动画。
- 页面滚动时可在导航下沿显示 1 px 朱砂进度线；它只表示滚动位置，不做装饰光带。
- 手机保留品牌行和三个文字入口，两行实色；不折叠成只有图标的菜单，不引入汉堡菜单。手机不显示滚动进度线。

### 5.2 首页

- 首屏仍是地球展厅：三维地球是主体，标题与入口是展签。地球偏右，桌面文字列在左；手机上下重排，文字在上、地球在下。
- 主标题用衬线大字、纸白；说明用 `stone`；主入口为纸白按钮，右侧配短箭头。按钮 hover 换 `paper-dim`，保留磁吸反馈但阴影改为中性黑。
- 保留现有首页文案、真实城市读取、Mock 标识和资源未就绪提示。**不新增长列表、搜索、关于入口、统计数字或第二组主按钮。**
- 地球只换色，不改交互数学：海洋与陆地为墨灰层次，经纬弧为低对比 `line` 系列，大气边缘为低不透明度纸白；城市点为朱砂小点，选中时放大并出现纸白短环。**不恢复冷青边缘光，不使用彩色光晕，不启用持续自动旋转。**
- 首屏可保留极轻的纸白展陈光与 112px 网格的极弱图纸线（如现有实现），但都必须是中性白、低对比、静态或缓慢呼吸；不遮挡文字与操作。

## 6. 作品目录

### 6.1 桌面

- 目录页顺序：页头（眉题编号、标题、说明）→ 目录条（真实件数、排序说明、查看全部等现有信息）→ 等距四列网格。
- **桌面四列等宽**，不再使用 v2 的第一张放大、第二张次大的主次网格。每列宽度一致、卡片高度一致、封面统一 16:10。
- 卡片顺序就是真实发布顺序，编号 01、02……只表示目录位置，不代表排名或精选。不要为了视觉节奏重排真实顺序。
- 卡片结构：封面（可叠编号）→ 作品名（衬线）→ 城市或“未设置城市”（`stone`，前置 4–5px 朱砂小点）。整张卡片只有一个进入详情的链接目标。
- 编号使用等宽数字，小号编号用 `accent-text`（5.54）或 `paper`；若编号压在封面上，必须带 `ink-950` 小底，不能直接压在复杂建筑画面上。
- hover／focus：边框升为 `line-strong`、封面轻微放大（约 1.02）、中性黑阴影出现；保留 v2 的卡片倾斜、景深与指针边缘光，但边缘光改为中性纸白。键盘焦点用 2 px 纸白焦点线，不被卡片裁切。
- 加载骨架、空目录、读取失败沿用现有真实状态与重试，不改业务文案结构。

### 6.2 中间布局与手机

- 1024–1279 三列，768–1023 两列，均等宽。
- 手机单列，顺序固定：页头 → 目录条 → 单张卡片（封面 → 编号／作品名 → 城市）。卡片间距 24–28，页面不横向溢出。
- 手机不因为“展签感”把作品名压到封面内；文字始终在图像下方独立成块，保证对比度。
- 手机点击反馈取代 hover：按下时卡片轻微下沉或封面微缩，松手回位；不做依赖悬停的信息。

## 7. 作品详情

### 7.1 桌面：左图右文

- 顶部保留“返回全部作品”。
- ≥1024 使用 12 列网格：**左侧观看区约 8 列，右侧信息列约 4 列，间距 40。** 观看区始终在左，展签信息在右。
- 左侧观看区：封面／真实预览画面、开始预览与现有控制条、放大与恢复入口。封面和观看画面固定在 `#0E0F10` 承托上，边框 1 px `line`，圆角不超过 4px；不加玻璃、不加彩色描边、不加厚相框。
- 右侧信息列顺序：编号／英文眉题 → 作品名（衬线大字）→ 城市 → 建筑介绍 → 建模说明（有内容时）→ 作品信息（模型格式、观看方式等真实元信息）→ 点赞／评论预留。
- “开始预览”保留为观看区内的唯一纸白主按钮，位于封面下方或观看框下沿；信息列不重复放置主按钮。次操作（返回、重试、恢复）用实色次按钮或文字按钮，不与主按钮争亮度。
- 信息列文字左对齐，最大宽度按阅读舒适度控制；长介绍自然换行，不压成窄栏，也不做成逐字动画。

### 7.2 手机：单列顺序

<768 改为单列，顺序固定为：

1. 返回全部作品；
2. 编号／英文眉题、作品名、城市；
3. 观看区：封面或真实预览画面、开始预览、现有控制条；
4. 建筑介绍；
5. 建模说明（有内容时）；
6. 作品信息：模型格式、观看方式等真实元信息；
7. 点赞／评论预留。

- 手机观看区初始高度约 16:10，宽度占满内容列；开始预览与结束逻辑不变。
- 城市为空的模型显示“未设置城市”，不使用错误色，也不因此隐藏。
- 放大查看仍是页内全视口覆盖层，不申请浏览器原生全屏权限，不新增页面。
- 不显示文件大小、三角面数、下载按钮、排名或“精选”标签。

### 7.3 状态与焦点

未启动、连接中、可交互、资源繁忙、断线、结束等状态沿用现有业务语义与 [动效设计 v1.0](动效设计v1.0.md) 的反馈规则，只换视觉：

- 状态文字使用语义色，容器用对应深色底；错误、警示、成功都不只靠颜色。
- 开始预览后焦点留在启动位置或移到观看区，不因换色丢失；结束后回到可再次激活的开始预览。
- 焦点线为 2 px 纸白，任何卡片、观看区、信息列都不能把它裁掉。

## 8. 动效原则

### 8.1 总则：不删减，只换色

**v3 不删减 v2 已有的任何动画，不缩短编排、不合并时间轴、不把正常模式简化为淡入淡出。** 所有动画的时长层级、缓动、GSAP／Flip 结构、打断与清理规则继续按 [动效设计 v1.0](动效设计v1.0.md) 执行；本方向只负责把颜色、光影和材质换成墨／纸／朱砂。

保留并强化：

1. 首页开场：标题分行揭示、导航就位、地球进入、城市点位错峰出现。
2. 地球拖动与短时惯性、城市点位与气泡、明确选中后的镜头联动。
3. 目录卡片入场、倾斜、景深、指针边缘光、磁吸按钮反馈。
4. 封面到详情的连续转场、详情信息分层入场。
5. 观看区的开始预览、真实首帧交接、放大／恢复、结束。
6. 现有减少动态分支与后台状态反馈。

“旧光效只换色”的具体含义：

- 暖金／冷青聚光 → 中性纸白低透明度光，或取消彩色只留中性明暗；
- 冷青边缘光、反光、彩色阴影 → 纸白边缘光或中性黑阴影；
- 玻璃、彩色半透明表面 → 实色墨面；
- 地球大气、点位光晕 → 纸白边缘与朱砂实点，不保留彩色 bloom；
- 所有时长、错峰、缓动、层叠顺序与打断行为保持不变。

### 8.2 新增交互式动效

在保留现有动画的前提下，新增以下五类交互，全部只在合适输入设备和非减少动态时启用：

1. **指针展陈光。** 精细指针且 `prefers-reduced-motion: no-preference` 时，加载一个固定层：560px 左右的纸白径向光（不透明度约 8%）平滑跟随指针，并带 24px 指针环；移到可交互目标上时指针环放大到约 56px，可显示短标签。指针光只用 `paper` 白，不替换系统光标；触摸设备不加载。
2. **轻视差。** 首页地球、标题、英文侧标可按指针位置或页面滚动产生 8–12px 以内的轻微位移；不改变可点击区域，不阻挡地球拖动，不与镜头补间抢同一属性。只使用 `transform`，不逐帧写 React 状态。
3. **导航跟随。** 1 px 朱砂指示线在当前项、hover 项和键盘焦点项之间移动（约 360ms），滚动进度线随页面滚动伸缩。减少动态时指示线直接切换位置，不做滑动。
4. **点位反馈。** 城市点位 hover／focus 时放大到约 1.3 倍并出现纸白短环；选中时约 1.4 倍、连接线以描边动画展开、气泡分层出现。反馈不使用朱砂或彩色的外发光，只允许实心点、短环、放大和中性白。
5. **预览转场。** 目录或城市卡片中的封面继续连续移动到详情观看框，时长与重叠按动效文件；真实首帧到达后才与模型画面交接，不做假的模型变形；快速导航、返回、缩放和卸载时恢复最终可见状态并移除克隆层。

### 8.3 减少动态是独立分支

`prefers-reduced-motion: reduce` 是主动选择，不是普通模式的简化版：

- 关闭指针光、视差、导航指示线滑动、点位缩放与光晕、封面克隆转场、开场镜头推进；
- 保留即时状态变化、清晰的静态高亮、短淡入、焦点立即可见和真实加载／错误提示；
- 气泡直接出现在最终位置，不播展开位移；缩略图与封面直接显示；
- 不暂停业务操作等待动画，不补播后台积压时间轴；
- 减少动态分支与普通模式共用同一业务状态和同一 DOM 顺序，不能因为省动画而少信息或改顺序。

触摸设备（`hover: none`、`pointer: coarse`）不启用指针光与 hover 视差；点击反馈仍保留，但以状态变化为主。

### 8.4 动效禁止项

- 金色、青色、朱砂色的发光、bloom、彩色阴影或彩色边缘光；
- 玻璃拟态、大面积模糊、持续噪点动画；
- 粒子、烟花、光带、无限自动旋转地球等新装饰动画；
- 用动画时长伪造上传、模型准备或网络耗时；
- 因换色而删除、合并或弱化现有动画。

## 9. 明确不采纳

以下内容不在 v3 范围内，也不得以“参考图里有”为理由加入：

| 不采纳 | 原因与边界 |
| --- | --- |
| 搜索入口、搜索页 | 首期只有 10 件作品，目录一次展示全部；搜索会增加交互与状态范围，不解决真实问题 |
| 关于页、“关于”导航 | 没有已确认的内容与业务依据，不新增页面；导航保留现有入口 |
| 文件大小、三角面数字段 | 不是观众决策所需信息，真实元数据也不稳定；详情只保留可核对的模型格式，不显示字节数、面数、面片量 |
| 来源不明的照片 | 封面只能来自团队真实模型渲染或已确认素材；不用网络照片、AI 重绘建筑或近似点云图冒充正式封面 |
| 假数据 | 不造假点赞、评论、浏览量、排名、精选、在线人数、AI 对话或统计数据；占位必须明确标注，Mock 标识保留 |
| 图片 A 中的搜索图标、“关于”入口、模型大小与多边形数 | 图片 A 只确认色彩方向、宋体标题、等距四列目录和左图右文详情；这些附加元素不采纳 |
| 金色、青色、彩色光、玻璃拟态、胶囊大圆角 | 与“墨·纸·朱砂”和夜间档案馆的克制方向冲突 |
| 自动旋转地球、新的常驻装饰动画 | 继续按动效文件不启用；后续若需要，必须单独评审暂停与用户接管 |
| 新业务功能（真实点赞／评论提交、下载、统计、打卡、路线、消息） | v3 只换视觉与版式，不扩展产品范围 |

- 本文不替代实施记录、截图验收、真机验收或性能验收；实施结果由实施记录单独记录。
