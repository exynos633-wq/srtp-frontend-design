## 3. 完整工程目标目录

```text
srtp网页/
├── 项目搭建计划.md
├── UI设计/                   # 深色视觉规范、参考图与动效设计
├── 工程设计/                 # 本轮工程设计
├── frontend/                 # 待初始化，前端独立工程
│   ├── README.md             # 安装、启动、构建、Mock/真实服务切换
│   ├── package.json
│   ├── package-lock.json
│   ├── .env.example          # 仅公开配置示例，无密钥
│   ├── <构建与类型检查配置>
│   ├── public/               # 适合公开交付的少量静态资源
│   ├── src/
│   │   ├── app/              # 入口、路由、全局布局
│   │   ├── pages/            # 页面组合
│   │   ├── components/       # 按钮、输入、作品卡片等共用组件
│   │   ├── features/
│   │   │   ├── globe/        # 地球、点位和气泡
│   │   │   ├── viewer/       # 观看区与实际选定的渲染实现
│   │   │   ├── admin/        # 登录、作品表单和上传
│   │   │   └── assistant/    # 完整 AI 组件的引入、配置、挂载与卸载
│   │   ├── api/              # HTTP 调用、错误转换
│   │   ├── types/            # 共享业务数据类型
│   │   ├── mocks/            # 按契约返回的开发样例
│   │   ├── assets/           # 字体、图标和小型界面素材
│   │   └── styles/           # 设计变量、基础样式
│   └── tests/                # 发布流程、权限、预览生命周期等关键测试
├── deploy/                   # 前端部署配置及操作说明，联调阶段补
└── .gitignore                # 排除依赖、构建结果、本地密钥等
```

后端及渲染服务由对应负责人维护，是否放同一仓库由团队决定；此处不虚建 backend 或 GPU 服务。现有大模型文件保持原位，不默认复制到 public 或提交 Git；正式模型存储由后端负责。
