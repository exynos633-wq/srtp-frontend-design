## 2. 渲染验证任务单

使用实际院落 GLB、较大长城 GLB、丘陵高斯 PLY，不以简单演示模型代替。分别记录设备、模型版本、浏览器、网络、首次可交互时间、操作帧率／响应、内存或显存、画面是否完整以及异常日志。

- 客户端候选：至少代表电脑与实际手机各一台，验证三类样例、加载、操作、结束后资源释放和重复进入；确认模型是否需要压缩或降低复杂度。
- 远程候选：实际工作站加外部网络电脑／手机，验证完整连接、输入、断线、手动重试和回收；若承诺 2–3 人独立操作，须实测互不影响和满载反馈。
- 无 GPU 服务器：当前不预设具备实时 CPU 渲染能力。只有用实际资源达到双方先约定的画质与交互阈值，才考虑纳入交付方案。

测试前由团队填入可接受的加载时间、帧率／响应、分辨率及并发目标；测量后记录达标／未达标，不事后改变门槛掩盖结果。若某模式未达标，明确采用资源优化、另一模式或缩小首期范围，并由团队确认。

## 3. 核心验收场景

- 地球城市卡片与目录只展示已发布作品；同城多个模型一个点位，气泡列出模型，点击具体模型进入详情；详情未点开始不加载完整模型或申请会话。
- 城市选填，未选城市也能发布并从目录进入详情，但不出现在地球卡片；只有无城市模型时地球提示前往目录，不能声称没有作品。
- 仅选省份仍为无城市；直辖市使用统一城市编号。无效城市编号被服务端拒绝，城市字典加载失败不清空已有值。
- 修改／清空已发布模型城市、下架城市最后一个模型后，刷新城市列表、点位、目录与详情；空城市点位消失，已失效气泡合理关闭。
- 登录失效后服务端拒绝管理操作；草稿详情不能通过公开接口读取。
- 不完整草稿能保存，缺发布必填项不能发布；上传失败不会假成功。
- 已发布元数据保存后公开内容更新；下架后新访问／新预览按约定拒绝。
- 远程模式下已有会话按既定规则继续；模型替换受服务端使用状态约束。
- 结束／返回／切换作品清理预览资源，重复点击不会泄漏会话；迟到的异步响应不恢复已关闭画面。
- 放大和恢复保持同一观看实例；繁忙、断线仅手动重试。
- 地球气泡可点击、可关闭、不越出屏幕；同城列表可滚动和键盘访问，邻近城市点位在真实中心数据下能选择。
- 完整 AI 组件正常挂载，入口不重复且不遮挡操作；深色主题、手机软键盘和层级适配正常；路由切换不重复挂载、卸载不残留。真实回答与失败反馈由组件提供；供应商密钥仅服务端持有。
- 评论与点赞明确预留，不出现假计数或可提交的假表单。

- 全部作品与城市卡片按最新发布优先，一次展示全部，不分页分类；纯文字介绍保留换行，不渲染富文本，不加作者／制作日期。
- 暂名“建筑模型展厅”，无 Logo 不阻断演示；AI 只挂公开端，后台不挂，未交付时无入口。首次演示的模拟成功与真实功能分开记录。

UI 统一采用深色 v1.0，至少覆盖 320、390、768、1440 CSS 像素宽度；实际手机浏览器另测触摸、滚动、软键盘、放大查看和长文本。检查键盘访问、焦点、深色表面的文字与控件对比。正常模式验收完整复杂动画及中断行为，减少动态偏好另验替代呈现，不能以此代替正常模式。

浏览器覆盖电脑主流 Chrome／Edge／Firefox／Safari、iPhone Safari 及主流安卓浏览器，具体设备与版本待联调登记，微信内置浏览器不在本期验收范围。流畅度优先，在保留核心复杂动画的前提下优先优化资源、像素比、阴影与模糊成本；不以所有历史浏览器或所有设备同画质作为承诺。

自动化重点放在发布资格、公开／管理权限、上传结果绑定及预览生命周期。视觉布局用代表视口截图检查；真实渲染与网络仍需实机，不用 Mock 测试代替。

## 4. 交付时应存在的文件

- 前端源代码、依赖锁文件、构建／类型检查配置、必要测试与运行 README。
- `.env.example`：公开 API 基址、开发 Mock 开关等；实际口令与密钥不得写入。
- 经双方确认的接口契约、正常与失败样例、变更记录。
- 部署说明：构建产物位置、HTTPS、API 转发、前端路由回退、资源存储及缓存、健康检查和回滚步骤。
- 渲染运行说明：服务维护人、启动方式、可用时段、离线处理及真实容量。
- 正式作品资料与资源清单、字体及图片来源许可、验收记录和已知问题。

GitLab 按会议约定分支开发、审核合并；实际仓库地址由团队提供。原始大模型不因初始化工程就提交仓库或上传到外部服务。
