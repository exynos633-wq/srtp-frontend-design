### 4.2 关键决策与理由

1. **ESLint 取代模板的 oxlint**：04 明确“ESLint + TypeScript 检查”；模板默认 oxlint 属初始化
   产物，故替换并删除其配置，不保留两套 linter。
2. **TypeScript 保持 6.0.x，不升 7**：`typescript-eslint@8.71.2` 的 peer 为
   `>=4.8.4 <6.1.0`，升 7 需强制忽略 peer；按“不强制绕过 peerDependencies”保持模板版本。
3. **路由表写成纯 TS（`Component` / `ErrorBoundary`，不用 JSX `element`）**：react-router 8
   的 `RouteObject` 支持这两个字段，路由配置与页面组件解耦，也避免把配置模块变成
   组件模块（react-refresh 规则）。
4. **`/admin` 用组件内 `<Navigate replace>` 跳转，而不是 loader `redirect`**：初版 loader 方案在
   初始 hydration 时会出现“空路由 + 缺少 HydrateFallback”警告并闪空页；改为组件跳转后
   警告消失、行为一致（已由单测与 e2e 覆盖）。
5. **懒加载用布局内的 `<Suspense>`**：公开端与后台各自的分支页面独立成 chunk（构建产物可见
   `HomePage-*.js`、`LoginPage-*.js` 等），首屏不加载其他分支；未引入路由级加载器或预建框架。
6. **Playwright 复用本机 Chrome 并显式绑定 `127.0.0.1`**：不下载浏览器即可跑冒烟；首次 e2e 因
   Vite 默认 `localhost` 探活超时（120 s）失败，改为 `--host 127.0.0.1` 后通过（见 §4.4）。

3. **错误归一**：所有失败转成 `ApiError`；2xx 但非 JSON 记 `INVALID_RESPONSE`，网络不可达记

4. **首期关闭自动重试**：Query `retry: false`，mutation 不自动重发；P05 的预览会话启动要用

   启用时界面显示“开发 Mock · 非真实接口”。
6. **一套数据派生多视图**：公开目录、地球聚合、城市气泡、后台列表都从同一份内存数据计算，

7. **上传与预览保持提案**：类型层只有 `UploadAsset` 与 `status`，没有发明分片、断点或会话

8. **中心缺失不伪造坐标**：广州市有城市无中心，作品照常发布、留在目录，但不生成地球点位。

### 8.2 关键决策与理由

1. **页面不缓存模型**：目录只读元数据；hover、进入详情、共享转场都不请求 `.glb`／`.ply`，
   也不创建预览会话。模型对象与视角应由后续真实观看器自己管理。
2. **错峰不排队**：每行一个时间线，行内 60 ms、单行 520 ms；后续行由观察器独立触发，
   长队列不会阻塞页面后面的内容。减少动态时全部卡片直接可见。
3. **返回恢复用一次性记忆**：`rememberDirectoryReturn` 记录 `scrollY` 与作品 id，详情返回后
   `takeDirectoryReturn()` 消费一次；焦点落到原卡片链接。直接进入详情没有来源，不伪造返回。
4. **模拟状态机与真实能力分开**：`PreviewViewer` 的 1400 ms 准备是**显式模拟**，开发构建可
   选择结果；页面固定显示“模拟场景 · 未连接真实渲染服务”，没有假首帧、百分比或自动重试。
   以后接真实渲染时只替换状态来源，不改变开始/结束/放大的外壳语义。
5. **迟到结果作废**：每次开始递增 attempt token；结束、切作品、路由离开或卸载会清理计时器，
   迟到的回调不能把已关闭的画面重新打开。
6. **放大不新建实例**：放大只是同一个观看区节点的定位/尺寸变化，Esc 或“恢复常规查看”回位，
   不重建场景、不重置视角；结束预览在放大中仍可执行且不自动关闭模态，两者语义分开。
7. **共享转场有严格来源条件**：`canUseCoverSource` 检查同作品、同 URL、可见区域和宽高比差
   < 8%；不满足就走独立入场，避免把卡片硬拉到不匹配的目标。详情 URL、数据与可用性不依赖
   动画完成回调；慢数据只显示真实加载。
8. **手机保留 16:10 封面**：视觉规范 §4.3 的“观看区初始约 340 高”与固定 16:10 封面、P06
   手机转场存在冲突；本阶段选择 16:10，以保证同一封面可衔接并让手机也有共享转场。已写入
   README 已知限制，后续若产品确认 340 高，需要同时调整封面裁切规则与转场判定。
9. **Mock 显式且仅开发**：新增 `cover-failure` 场景与 `?mockScenario=` 首次加载选择，
   仅 DEV 且 `VITE_ENABLE_MOCKS=true` 生效；生产失败不回退 Mock。封面失败显示“封面暂不可用”，
   不冒充模型或正式封面。

### 9.2 关键实现与取舍

1. **只画有作品且有中心的城市**：数据来自 `GET /api/globe/cities` 的 `GlobeCity`；广州因

### 10.2 关键实现与取舍

1. **一个气泡、一个状态**：同一时刻只渲染一个 `CityBubble`；切换城市直接替换，不排队。
   悬停打开不移动镜头；点击／键盘背面聚焦才播 500–800 ms 镜头。
2. **DOM 顺序即焦点顺序**：气泡渲染在选中点位之后，Tab 自然得到
   点位 → 关闭 → 城市作品 → 下一点位；不使用焦点陷阱。`Esc` 关闭后焦点回点位，
   抑制标记避免立即重开。
3. **命中按最近城市**：上海与杭州在演示视角下约 10 px，48×48 命中区重叠；点击按投影坐标
   选最近城市，不缩小命中区。气泡覆盖相邻点时，键盘或关闭后重新点选是支持路径。
4. **连接线与定位不逐帧 React**：`SceneSync` 每帧写点位 transform、气泡层位置和 SVG 线端；
   气泡尺寸由 `ResizeObserver` 测量后进入 state；没有按帧 `setState`。
5. **玻璃预算**：桌面导航面积＋气泡面积超过视口 22% 时气泡回退实色；手机气泡固定 280 px
   宽并回退实色。短视口（390×430）内列表在气泡内部滚动，列表滚动不拖动地球。
6. **P06 最小接入**：只把被点击的方形缩略图作为转场来源；整个城市卡片或多件封面不会
   同时飞入详情。目标是详情数据与 URL 的可用性不依赖动画回调。
7. **失败与空**：城市作品读取失败在气泡内手动重试，不创建预览、不自动重试；空列表明确
   目录仍可能有其他城市作品并给出 `/works`。
8. **减少动态**：气泡直接呈现，镜头直接跳转；不把正常模式的镜头联动改成统一淡入淡出。
