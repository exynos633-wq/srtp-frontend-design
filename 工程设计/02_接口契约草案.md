# 接口契约草案 v0.2

日期：2026-10-17。全部路径、字段和状态为待前后端评审的提案，不代表接口已存在。评审后固定版本，Mock 与真实实现使用同一契约；变更必须同步双方。

2026-10-18 更新：用户已确认城市选填、标准省市选择、同城模型合并点位；取消建筑经纬度与后台地图选点。产品规则详见 [城市归属与地球聚合](05_城市归属与地球聚合.md)，接口实现仍待前后端确认。

## 1. 通用规则提案

- API 前缀 `/api`，JSON 字段用 camelCase，编号为不透明字符串，时间用带时区的 ISO 8601。
- 成功响应直接返回对象；列表返回 `{ "items": [] }`。已确认首期 10 个模型，一次返回全部已发布作品，按发布时间降序、id 稳定排序；城市卡片中的模型同序。不实现分页或分类，以后引入需同步修改契约。
- 错误格式：`{ "error": { "code": "VALIDATION_FAILED", "message": "请补齐发布资料", "fields": { "name": "名称不能为空" } } }`。fields 仅在字段校验失败时提供。
- 建议状态码：400 请求格式错误，401 未认证，403 无权限，404 公开作品不存在或不可公开，409 状态冲突，413 文件过大，422 字段校验失败，429 请求过多，503 预览服务不可用或容量满。
- 同源部署和 HttpOnly Cookie 会话为认证提案，具体有效期、Cookie 属性、CSRF 防护、跨域开发方式由后端确认后落地。未确认前不固化为 token 本地存储。
- 客户端校验改善反馈，发布资格、权限、格式及大小校验由服务端最终执行。AI 供应商密钥不进入前端。

## 2. 作品数据

未设置城市的公开作品示例（仍可正常发布并通过全部作品浏览）：

```json
{
  "id": "work_demo_001",
  "name": "演示作品",
  "city": null,
  "coverUrl": "/demo/cover.webp",
  "modelFormat": "glb",
  "description": "仅用于开发演示的建筑介绍",
  "modelingNote": null
}
```

已设置时 city 为 `{id, name, province: {id, name}}`。写入使用 `cityId: string | null`，名称由标准字典派生；后台读取同时返回 cityId。PATCH 省略 cityId 不修改，显式 null 清空；未选城市或只选省份时 cityId 为 null。无效城市编号返回 422 `VALIDATION_FAILED` 并指向 cityId，不把非空无效编号当作未填。

建筑经纬度和自由所在地字段从作品契约移除。城市字典单独维护中心坐标，建议使用 WGS84，经度 -180～180、纬度 -90～90；实际来源与坐标体系待后端确认。高斯资源类型使用 `gaussian-ply`，避免与普通点云 PLY 混淆。

后台作品另含 `status: draft | published | offline`、`modelAssetId`、`coverAssetId`、`updatedAt`。草稿的未填业务字段允许 null；发布后必填字段必须完整。公开数据不默认包含模型下载地址或内部存储路径。

发布必填：名称、封面、已接收且校验通过的模型资源、建筑介绍。城市与建模说明可空。城市字典中心缺失不变为作品发布条件；缺少中心数据时不生成错误点位，后台提示地球发现暂不可用。字段长度、允许封面格式和文件大小上限由前后端评审填入。

介绍与建模说明均为支持换行的纯文字字符串，页面按文本显示，不解析 HTML 或 Markdown。不增加作者／团队和制作日期业务字段；用于排序的发布时间、更新时刻仍可作为服务端元数据。AI 辅助整理内容与封面，未知身份和城市不猜测；开发占位属于 Mock 数据，不改变正式发布校验。

## 3. 业务端点提案

| 方法与路径 | 请求 | 成功响应／行为 |
| --- | --- | --- |
| GET `/api/works` | 无 | 200 `{items: PublicWork[]}`，仅已发布作品 |
| GET `/api/works/:id` | 无 | 200 PublicWork，不公开则 404 |
| GET `/api/admin/provinces` | 管理员会话 | 200 `{items: [{id,name}]}`，标准省级选项 |
| GET `/api/admin/cities?provinceId=:id` | 管理员会话 | 200 `{items: [{id,name,provinceId}]}`，城市字典选项 |
| GET `/api/globe/cities` | 无 | 200 `{items: [{id,name,province,center,workCount}]}`，仅有已发布模型且中心有效的城市 |
| GET `/api/globe/cities/:id/works` | 无 | 200 `{city,items: PublicWork[]}`，该城市当前全部已发布模型；城市有效但无公开模型时 items 为空 |
| POST `/api/auth/login` | `{username,password}` | 200 `{user:{id}}`，建立会话 |
| GET `/api/auth/me` | 会话 | 200 `{user:{id}}`，失效 401 |
| POST `/api/auth/logout` | 会话 | 204，失效服务端会话 |
| GET `/api/admin/works` | 管理员会话 | 200 `{items: AdminWork[]}` |
| GET `/api/admin/works/:id` | 管理员会话 | 200 AdminWork |
| POST `/api/admin/works` | 已填写的草稿字段 | 201 AdminWork，状态 draft |
| PATCH `/api/admin/works/:id` | 变更字段 | 200 AdminWork；省略不修改，null 明确清空可空字段 |
| POST `/api/admin/works/:id/publish` | 空对象 | 200 AdminWork；服务端执行发布校验 |
| POST `/api/admin/works/:id/unpublish` | 空对象 | 200 AdminWork，状态 offline；拒绝新的公开预览 |

全部 admin 路径由服务端验证管理员会话。已发布元数据更新仍需满足发布条件；保存后公开读取应获得更新结果。重复发布或下架到同一状态建议返回当前作品，不产生重复副作用。

地球 center 为 `{longitude,latitude}`，是城市中心，不是建筑精确位置；province 为 `{id,name}`。未知城市编号读取返回 404 `CITY_NOT_FOUND`。城市卡片接口不返回草稿／下架作品，也不创建预览会话。workCount 只统计已发布模型；空城市不出现在地球列表，未设置城市的已发布模型仍保留在 `/api/works`。

作品保存城市变更／清空、发布和下架后，前端刷新全部作品、详情、地球城市与相关城市模型列表。最终城市列表为空时关闭已失效气泡；城市字典加载失败保留已有 cityId，不静默提交清空。省级筛选不是作品归属，城市字典需要统一处理直辖市；首期仅国内，不实现海外城市选择。

模型资源绑定或替换通过 PATCH 的 modelAssetId，但服务端必须检查状态和资源使用情况。远程模式已发布作品需先下架，已有预览未结束则返回 409 `MODEL_IN_USE`；失败保留旧绑定及下架状态。不得只依靠前端按钮禁用实现约束。

## 4. 上传约定

先定义上传结果：`{assetId, kind, originalName, sizeBytes, status}`，kind 为 model 或 cover；status 区分 receiving、validating、ready、failed。仅 ready 的资源能用于发布。传完字节不等于模型可渲染。

传输端点暂不定稿：后端需选择直接上传、签名直传或分片上传，并确认大小上限、重试／续传、取消、完整性检查、资源查询和未绑定文件清理。前端上传模块对页面提供开始、进度、成功资源编号、失败和取消结果。后端没有真实字节进度时只显示阶段。

Mock 阶段只能演示表单与状态；实际大文件上传开发必须等待上述选择。封面与模型可以分别失败、重试，不清空其余表单字段。

## 5. 预览边界

建议通过 GET `/api/works/:id/preview-config` 获取公开预览配置；管理员使用 GET `/api/admin/works/:id/preview-config`，每次按当前作品状态与权限检查。获取配置本身不分配渲染资源。具体格式依首期验证结果定稿。

- 本地分支：`mode: client`，提供受控访问的资源地址、资源版本、格式和默认视角；不创建远程会话。
- 远程分支：`mode: remote`，点击开始后 POST `/api/preview-sessions`，请求 `{workId}`；成功 201 返回 `{sessionId,status,expiresAt,connection}`。
- connection 是协议专属结构，待选择传输方式后定义。不能用一个 connectionUrl 代替完整的信令、认证、控制和连接流程。
- GET `/api/preview-sessions/:id` 提议用于查询状态；DELETE 同一路径结束会话，重复结束幂等返回 204。会话只允许创建者访问，公开访客如何绑定会话身份由后端确认。
- 资源满返回 503 `PREVIEW_BUSY`，节点离线返回 503 `RENDERER_OFFLINE`，作品下架返回 404 `WORK_UNAVAILABLE`。保留介绍与封面，手动重试，不排队、不自动新建会话。

远程协议签字前必须补齐：传输与信令、控制事件及坐标、默认相机、画面尺寸变化、访客身份、初始化超时、心跳／租约及断线回收、重复申请去重、创建成功但客户端离开的清理。关闭网页不能保证结束请求送达，必须由服务端超时兜底。数值依据验证确定。

本地与远程配置仅为边界草案，不要求首期同时实现。若选择客户端，需同时重新评审模型替换与旧资源访问规则。

## 6. AI 客服交接

AI 助手属于首期，由其他成员实现；2026-10-18 更新为按完整组件交付规划，前端只负责挂载和页面适配。实际包、脚本或其他嵌入形式以及配置尚待负责人交付确认，不代表组件已可用。

组件负责人提供聊天入口与面板、消息发送和回答展示、会话及流式处理、加载／失败／重试反馈和内部展开动画，并负责对接其服务端。主站不重复实现聊天面板、AI 请求封装或供应商调用。本接口草案不再定义主站的 `/api/ai/chat` 路径；组件内部协议由负责人维护。

交接最少提供：

- 安装／引入方式、所需依赖及与 React 19 的兼容说明，挂载示例和卸载／销毁方式。
- 必需的公开配置、测试服务环境与正常／失败演示；供应商密钥由服务端保管。
- 深色主题配置方式、浮动位置与层级、手机尺寸和软键盘适配要求；通过公开接口调整，不直接覆盖组件内部 DOM。
- 入口由组件自带还是主站挂载后通过公开控制方法打开，避免出现两个悬浮入口；挂载页面及是否可常驻切换路由。

主站负责挂载容器、引入配置、位置／层级／安全区适配及卸载清理，避免遮挡城市卡片和观看控制。已确认仅在公开展示区挂载，后台和后台登录页不挂载；组件未交付／未启用时隐藏入口。已接入后的临时服务失败由真实组件反馈，不用假回答替代。当前不要求传入作品上下文，若组件后续提供该能力再约定。
