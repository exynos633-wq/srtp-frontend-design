# 演示地球纹理

`earth-demo.png` 保留为历史演示文件：P07 阶段绘制的深色等距圆柱演示纹理，不再作为
v3 默认纹理使用。

`earth-v3.png` 是 v3 中性色重着色版本（4096×2048 PNG），由 `earth-demo.png` 重映射得到：

- 来源：Natural Earth `ne_110m_land` 公共领域陆地数据
  <https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/>
- 原始纹理：按 `#0D1D27` 海洋、`#28454B` 陆地、`#395962` 海岸线绘成 4096×2048 等距圆柱
  纹理，南极洲保留在底部。
- v3 重着色：用 Python/Pillow 按“每个像素到原始三色的最近距离”归类（抗锯齿混合像素取
  最近基色），再映射为 `#0A0B0C` 海洋、`#262724` 陆地、`#5A564E` 海岸线；输出 PNG 仅含
  这三种颜色，尺寸与投影不变，`earth-demo.png` 未覆盖。
- 使用限制：两个文件都只用于验证球体、城市中心点位与交互路径。边界、地形、光照和真实
  地球影像均未交付，不能据此声明正式地理效果已验收。正式纹理到位后替换文件，并同步
  更新视觉验收记录。
