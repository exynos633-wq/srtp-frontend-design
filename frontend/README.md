```powershell

## 数据层与开发 Mock（P03）

数据边界按 [接口契约草案](../工程设计/02_接口契约草案.md)（v0.2，**未经后端签字**）建立，
真实路径、字段与错误码仍可能变化；上传与预览的未定部分保持提案，没有固化成协议。

- **类型**（`src/types/`）：`PublicWork`（公开端）与 `AdminWork`（后台，含 `status`、
  资源 id、`updatedAt`）分开；`cityId` 在请求体里省略＝不修改、`null`＝清空；
  作品**不含建筑经纬度**，位置只由 `cityId` 决定。`City`、`Province`、`GeoPoint`、
  `GlobeCity`（含 `workCount`）、`UploadAsset`、统一错误体同在类型层。
- **请求层**（`src/api/http.ts`）：统一基址、`credentials: 'include'`、JSON 解析、
  错误归一为 `ApiError { status, code, fields }`、透传 `AbortSignal`（取消不算失败）。
  网络不可达 → `NETWORK_ERROR`，2xx 但非 JSON → `INVALID_RESPONSE`，不会把失败当成功。
- **缓存**（`src/api/queryKeys.ts` + `src/app/queryClient.ts`）：Query 键集中定义；
  首期关闭自动重试与窗口聚焦重取，`staleTime` 30 s；写操作不重发。
  模型对象、逐帧相机、视频流一律不进 Query 缓存（P05／P18 自行管理生命周期）。
- **Mock 数据**（`src/mocks/`）：一套内存数据派生出公开目录、城市聚合与后台列表，
  写入后立刻一致。含 **10 件已发布**演示作品（3 件真实样例 + 7 件明确占位）、
  2 件草稿、1 件已下架；城市含同城多件、无城市、中心坐标缺失（广州市，不生成地球点位）。
- **演示账号**：`admin` / `admin`，**仅用于 Mock 演示，不是安全方案**；Mock 会话只在内存，
  刷新页面即退出、数据复位，没有持久化。
- **可控场景**：`normal`／`empty`／`list-failure`／`cover-failure`／`globe-empty`／
  `city-empty`／`city-list-failure`／`auth-expired`／`auth-forbidden`／`login-error`／`validation-failure`／`model-in-use`。
  开发时在控制台用 `window.__mockControls.setScenario('empty')` 切换，
  `window.__mockControls.reset()` 恢复初始数据；
  Playwright 也可用 `?mockScenario=empty|list-failure|cover-failure|globe-empty|city-empty|city-list-failure`
  在首次加载前选择场景。`globe-empty` 只清空城市点位，公开目录仍保留 10 件已发布作品；
  `city-empty`／`city-list-failure` 只影响城市气泡的作品列表，地球其他城市与公开目录不受影响。
- **失败不回退**：关闭 Mock（或生产构建）时请求真实发出，失败按错误处理，**不会**落到假数据。
  注意 `npm run dev` 对未知 `/api/*` 会返回 `index.html`（HTML 200），客户端会报
  `INVALID_RESPONSE`；接入真实后端时应配置开发代理，避免 SPA 回退吞掉 API 的 404。

`/auth/me` 返回未登录；真实会话刷新能否保持登录由后端方案决定，不存 token 或本地登录布尔值。

## 草稿表单与未保存保护（P11）

`/admin/works/new` 可保存不完整草稿，首次成功后进入该作品编辑路由；再次保存只 PATCH 变化字段。已发布作品使用“保存并更新公开内容”，服务端校验失败时保留输入并聚焦首错。草稿的模型／封面可选择开发模拟资源，见 P12；真实上传尚未接入，不把本地文件名当作资源编号。

省份只是城市筛选；仅省份不保存位置，切省清除不适用的城市，主动清除才发送 cityId:null，未修改则省略。省市字典故障保留原 cityId，允许保存其他字段和手动重试。当前字典仍是 Mock 样例，不代表全国数据已交付。

未保存状态以最近服务端确认快照为基线，改回原值即恢复 clean。站内离开可取消，浏览器刷新／关闭提示受浏览器控制。退出登录在请求前确认，等待退出时暂停表单编辑；成功只放行对应登录页跳转，失败恢复编辑和保护。保存 401／403 撤去敏感管理内容；退出后迟到的保存结果不会重新填回草稿缓存。Mock 刷新仍复位，不提供持久化草稿备份。

## 草稿模拟上传（P12）

只在开发构建且 MSW 已实际启用时开放。模型与封面分别经历“模拟传输中 → 模拟服务端验证中 → ready／失败”，显示的百分比明确为模拟；客户端仅提交文件名、大小与 MIME 等说明信息，**不读取或传输模型文件内容**。这不是正式上传 API，不验证真实格式、完整性或可渲染性，不代表真实文件已经存储。

只有模拟服务端登记为 ready 且种类正确的资源编号能保存绑定；未知／验证中／失败／种类错误均被拒绝。选中文件或 ready 但未保存都算未保存内容；有待处理或失败选择时先完成、重试或取消，再保存。未选择文件仍可保存空草稿。保存不会自动发布。模型与封面互不清空，失败或取消新选择保留旧绑定；P13 起草稿／下架作品可替换资源，已发布作品需先下架。

取消、重选、切作品或卸载会忽略旧请求并清理本地封面对象 URL；不把 File 放入查询缓存。上传开始或轮询的 401／403 与其他管理请求共用认证清理。刷新后 Mock 数据与未保存文件复位；正式类型细则、大小上限、分片／续传、取消与完整性规则仍待确认。

开发控制台可设置 `upload-cover-failure`、`upload-model-failure` 或 `upload-validating` 后重新选择文件。失败场景切回 `normal` 后点击该项重试；验证停留场景取消并重新选择。生产构建或 MSW 未启用时入口关闭，API 客户端也拒绝发模拟请求，不从真实网络失败回退假成功。

## 发布／下架、替换约束与缓存刷新（P13）

管理列表和编辑表单都可发起 Mock 发布／下架，服务端响应是状态、公开目录和城市列表的唯一依据。pending 期间按钮禁用并防重复点击；失败不清空字段、不假装成功，422 字段错误可在表单定位首错，列表失败提供“去编辑补齐”。下架使用 `window.confirm`。

发布要求名称、ready 模型、ready 封面和建筑介绍；省份／城市与建模说明选填，没有预览成功门槛。未保存的新作品必须先保存草稿；有未保存文本、文件或 ready 未保存资源时发布按钮禁用并提示先保存，保存和上传都不自动发布。已发布作品只能改资料，直接替换／清空模型或封面由 MSW 拒绝（`409 WORK_PUBLISHED`），需先下架。

草稿／下架作品可选择新资源并手动保存；`model-in-use` 409 保留旧绑定、offline 状态、其他字段和本次选择，切换回正常场景后手动重试保存，仍需手动再发布。重复发布／下架到同一状态幂等，不重复更新时间戳。保存城市变更、发布、下架都会失效 `works`／`admin`／`globe` 相关查询；表单不订阅自身作品查询，避免 dirty 输入被后台重取覆盖。

公开详情每次进入重新确认公开状态；新开始／手动重试模拟预览前用既有 `getPublicWork` 检查，不新增 preview 端点。已开始的模拟观看实例在作品下架后保留，结束后新申请或重试被拒绝。下架最后一件城市作品会移除点位；气泡消失后焦点回到地球舞台。

服务端已提交的保存／发布／下架即使回包晚于退出，也必须先失效公开 `works`／`globe` 缓存；私有 `admin` 缓存、私有数据和 UI 仍受 session／mounted 保护，退出后不回填。该边界由列表、表单动作和保存的迟到成功回归覆盖。以上均为 Mock 边界，真实发布／下架服务、权限和资源占用协议未接入。

```

这是开发演示开关，生产构建仍关闭 Mock；不修改 `.env.example` 默认值，也不要求改 `.env.local`。

演示顺序：首页空间开场与城市点／镜头联动 → 具体封面进入详情、开始/结束模拟预览 → 后台登录 → 新建草稿并选择本地文件做 metadata 模拟上传 → 填写名称/介绍/省市 → 保存同一 id → 手动发布 → 城市、目录可见 → 编辑/清空城市仍目录可见 → 下架 → 目录/最后城市点位移除 → 新详情 404、新预览拒绝。保存和上传不会自动发布；AI 未交付，无入口。

P14 实测：
- 正常模式三组复杂动画均实际运行并记录关键帧：首页空间开场、城市点位/镜头联动、具体封面到详情连续转场；手机 390 设备模拟也验证。
- 动画中拖动接管、快切/返回、resize、减少动态独立分支、残留克隆/遮罩/放大层与焦点由 Chrome E2E 覆盖。
- 首页、作品目录、公开详情、登录、管理列表、新建、编辑、管理员预览在 320／390／768／1440 均做布局/溢出/主要操作可达检查；桌面 Chrome 设备模拟，不是真机。
- 完整 Mock 业务流通过：草稿 → 模拟 ready 资源 → 保存同 id → 发布 → 目录/城市 → 清空城市仍目录 → 下架 → 目录/最后点位移除；新详情 404、新预览拒绝；AI 入口不存在。自动演示流会先下架杭州原占位 `模型占位 06` 以验证最后点位 4→3；默认五分钟手动脚本使用初始数据、不改这个隐藏夹具，城市点位总数保持 4（见验收记录 §3）。
- 当前 192 条单测、89 条 Chrome E2E；真实上传、真实模型渲染、远程会话、真实认证安全、AI、并发与线上部署仍未接入。P14 不构成这些能力的验收。

## 样式与设计变量（P02）

样式分两层：`src/styles/tokens.css` 只放设计变量，`*.module.css` 组织局部样式；页面里不写
行内颜色，也不从参考图吸色推算——数值一律来自
[视觉规范 v1.0（深色）](../UI设计/视觉规范v1.0（深色）.md)。

- **颜色**：页底 `#080D12`、面板 `#121D26`、图像承托 `#20272B`、输入底 `#0D161E`；主文字
  `#EBF2F5`、次文字 `#A8BAC4`、辅助 `#879CA8`；主强调 `#54C8C1`（按钮深色字）、冷银
  `#C6E2E6`；错误／警示／成功各三色，禁用三色。命名见 `--color-*`。
- **字号**：标题 34/42、建筑标题 20/28、正文 16/28、按钮与标签 14/20、字段说明 14/22、
  英数元信息 12/18；手机 <768px 由 tokens 覆盖为 28/36 等。
- **间距与布局**：4–48 的 `--space-*`；导航 72／手机 56＋44，侧边距 32／16，内容上限 1280。
- **圆角／层级／动效**：`--radius-overlay|panel|control`、`--z-nav|overlay|modal`、
  `--dur-fast 120ms`–`--dur-scene 600ms` 与两条缓动。GSAP 时间线使用同一组时长变量。
- **玻璃规则**：`--glass-nav`（`#080D12` 92% + 12px 模糊）用于桌面首页导航，
  `--glass-panel`（`#121D26` 88%）用于城市气泡；手机导航与超出玻璃面积预算的气泡回退实色。
  其余界面一律实色。
- **图像承托**：封面／占位统一铺 `#20272B`，模型画布也用同一底色，不额外叠渐变。
- **减少动态**：`prefers-reduced-motion: reduce` 时把时长变量置 0；P04–P06 的目录揭示、
  详情入场与封面转场，P07 首页空间开场与 P08 气泡／镜头联动，均提供独立的直接呈现，
  不是把正常模式统一改成淡入淡出。
- **焦点**：`:focus-visible` 统一 2px 深色间隔＋2px `#8FE1DB` 焦点线，覆盖链接、按钮、字段、
  `[tabindex]`；不支持 `:focus-visible` 的旧浏览器回退为 outline。
- **字体**：思源黑体 SC／Inter／IBM Plex Mono **未入库**，当前使用
  `"Source Han Sans SC", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui` 回退栈，
  等宽元信息用 `ui-monospace` 回退。正式字体需从官方项目取得并保留许可，替换时只改
  `--font-*` 变量，不改页面。

## 已知限制（P14）

1. 登录与管理列表、预览、发布／下架已消费 API 草案；新建／编辑已接草稿保存，草稿上传与发布／下架均为 MSW 模拟，真实协议待确认，没有真实后端权限和数据流程。
2. Mock 是演示与测试替身：内存数据、假登录、假资源状态，**不能当作认证或权限方案**；
   刷新即复位，没有持久化。
3. 真实接口未签字：路径、错误码、字段仍可能变化；上传与预览端点保持提案，未固化为协议。
4. **详情观看区没有加载真实模型，也没有真实渲染器／预览会话**。详情里的“准备中／可交互／资源繁忙／
   离线／断线／失败／结束”是本地模拟状态机（准备 1400 ms），开发构建可选模拟结果；页面明确
   标注模拟，不把倒计时或占位画面当作真实首帧。Three.js／Fiber 目前只用于首页演示地球。
5. 共享封面转场已接“目录→详情”和“城市气泡→详情”。首页已有演示地球、4 个 Mock 城市点、
   单气泡城市作品列表与镜头联动；真实城市中心、正式地球影像与真实模型预览仍未接入。
6. AI 助手组件未交付：没有入口、聊天 UI、假回答或供应商密钥；只保留后续挂载位置的设计边界。
7. 封面失败、列表空／失败、详情 404／失败、预览繁忙与结束、首页城市空／失败均有自动化用例；
   真实网络抖动、服务端 5xx 语义、超时与重试策略仍未经真实后端验证。
8. 字体未入库（见上），当前是系统字体回退，不能声称已使用思源黑体或 Inter。
9. favicon 待 Logo 确定，先用空 data URI 避免 404。
10. 开发服务器能回退深层路径，**不等于**生产静态托管已配置页面路径回退；同样，dev 对未知
    `/api/*` 返回 HTML 也说明接入后端前必须配好代理或改写规则。
11. 页面走查覆盖 320／390／768／1440 CSS px，但只在 Chrome 上；真机、Firefox、Safari、
    200% 缩放与屏幕阅读器未验证。
12. Playwright 89 条覆盖公开端回归及后台登录、失效、403、退出、返回路径、管理列表／授权预览、发布／下架生命周期、P14 完整演示流、窄屏与键盘提交；
    仅验证 Mock 权限行为，不验证真实安全性、渲染性能、视觉像素比对或生产部署；走查截图未入库。
13. **正式地球资产与城市中心字典尚未交付**：当前地球是 Natural Earth 110m 陆地派生的演示纹理，
    4 个城市点是 Mock 坐标；不能声称正式地理效果、正式城市中心或真实地球影像已验收。
14. 首页 Three／Fiber chunk 约 566 kB，构建有 >500 kB 警告；没有正式素材下的首帧、帧率、
    显存与重复进入内存数据，也没有做通用拆包。本阶段没有测量帧率，不声称性能达标。

### P08 的取舍

- 同一时刻只渲染一个气泡；桌面悬停 120 ms 打开、移入卡片不关闭，指针离开点位／卡片 200 ms
  后才关闭。悬停不移动镜头；只有点击、键盘聚焦背面城市或 Selected 状态才播 500–800 ms 镜头。
- 键盘顺序直接利用 DOM 顺序（点位 → 关闭 → 城市作品链接 → 下一个点位），不做焦点陷阱；
  `Esc` 关闭后把焦点还给点位，并用抑制标记避免立刻重开。
- 上海与杭州在演示视角下相距约 10 px，两个 48×48 命中区会重叠；实现按投影坐标取最近城市，
  不缩小命中区。气泡靠近点位时会覆盖相邻点，此时用键盘或关闭后重新点选。
- 气泡玻璃面积与导航一起按视口 22% 预算计算，超出时气泡回退实色；手机固定 280 px 宽，
  短视口下列表在内部滚动，列表滚动不穿透到地球。
- 城市方形的气泡缩略图与详情 16:10 封面视为同一封面的可衔接裁剪；仅被点击的那一件封面
  进入共享转场，城市卡片或多件封面不会整体飞入详情。
- 当前没有测量帧率，也没有正式地球素材下的性能结论；不把“动画能运行”写成帧率达标。

### P07 的取舍

- 只显示“有已发布作品且中心有效”的城市：北京 3 件、上海 2 件、杭州 1 件、深圳 1 件，共
  4 个点；广州中心缺失不补默认坐标，无城市作品不进入地球。点位按城市而非模型数。
- 首页城市点与气泡、镜头联动在 P08 接入；P07 阶段仅验证点位与选中提示的版本已被覆盖。
- 开场约 1.33 s，包含导航、镜头推进、地球转向和点位错峰；拖动、滚轮、键盘或点选会立即
  接管并停止开场。减少动态时直接呈现稳定场景。
- 首页地球外径在 1440 宽下约 760 px；手机 390 宽约 405 px，320 宽按比例缩小；舞台高度正好
  填满导航以下视口，无横向／纵向溢出。

### P04–P06 的取舍

- 视觉规范 §4.3 的“手机观看区初始约 340 高”与固定 16:10 封面、P06 手机共享转场存在冲突。
  当前选择 **16:10 封面**：手机详情初始观看区随封面比例（390 宽时约 224 高），以保住
  “同一封面可衔接裁切”的连续转场；这是阶段取舍，不是对 340 高的最终否定。
- 目录卡片错峰使用 `IntersectionObserver` 按行触发，单行 520 ms、行内错峰 60 ms；减少动态时
  直接显示全部卡片，不隐藏等待。
- 转场来源只在同作品、同封面 URL、可见且可衔接裁剪时启用；目录卡片保持 16:10（宽高比差 < 8%），
  城市气泡的方形缩略图视为对同一封面的裁剪。其余情况走独立详情入场，不伪造来源卡片。
